- **拖拉调尺寸**：贴近列边界拖 → 改列宽；贴近行边界拖 → 改行高；拖右下角手柄 → 改整表宽高（拖动过程只更新预览，松手才落盘）

- 内部用「逻辑矩阵」模型（`buildTableGrid` 把 colspan/rowspan 展开成 r×c 矩阵）统一管道表格与 HTML 表格的导航 / 选区 / 合并语义
