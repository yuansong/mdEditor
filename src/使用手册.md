# mdEditor 使用手册（完整参考指南）

mdEditor 是一款**块级所见即所得（WYSIWYG）的 Markdown 编辑器**：正文即写即得排版效果，无需切换预览；同时保留完整 Markdown 源码兼容性——所有内容都能以纯 Markdown 语义存储，导出走原生语法。本手册覆盖全部功能，可滚动通读。

---

## 1. 快速上手

1. 启动即进入「欢迎页」标签，直接开始输入；`Ctrl+N` 新建、`Ctrl+O` 打开。
2. 左侧竖向工具栏提供常用入口；顶部 `« / »` 开合文件面板。
3. `Ctrl+/` 在**渲染态（所见即所得）**与**源码态**之间切换。
4. `Ctrl+S` 保存；标签上的 `•` 表示有未保存修改。

## 2. 界面布局

| 区域 | 说明 |
| --- | --- |
| 菜单栏 | 文件 / 编辑 / 格式 / 视图 / 插入 / 工具 / 帮助 |
| 左侧工具栏 | 新建、打开、保存、导出、撤销重做等；可 `Ctrl+Shift+B` 隐藏/恢复（隐藏时窗口左缘出现 `»` 按钮） |
| 文件面板 | 两个标签页：**文件列表**（逐级浏览磁盘目录）、**大纲**（当前文档标题树，点击跳转） |
| 编辑区 | 块级 WYSIWYG；每个块（标题/段落/列表/引用/代码）独立渲染与编辑 |
| 状态栏 | 字数（点击看详情）、保存状态、当前模式 |

### 2.1 视图模式

- **单栏编辑**（默认）· **双栏**（`Ctrl+Shift+D`，左源码右预览，双向滚动同步）· **全屏**（`F11`）。
- 双栏下：源码侧滚动/光标带动预览；拖动预览滚动条反向带动源码。

## 3. 文件管理

### 3.1 基本操作

| 功能 | 快捷键 |
| --- | --- |
| 新建 | `Ctrl+N` |
| 打开 | `Ctrl+O` |
| 保存 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |
| 全部保存 | `Ctrl+Alt+S` |
| 关闭当前标签 | `Ctrl+W` |

- 保存自动写入**版本历史**快照（存于文档目录 `.mdeditor-history/`）；「文件 → 版本历史」可对比、回滚。
- 未命名文档实时**草稿保护**：崩溃 / 断电后重开可恢复。
- 导出：HTML（带样式与代码着色）、PDF、图片，入口在「文件 → 导出」。

### 3.2 文件列表面板

- 逐级浏览：点击目录进入、面包屑/上级返回；双击 Markdown 文件在编辑器打开。
- **默认目录**：设置 → 通用 → 「文件列表默认目录」。启动优先级：**上次访问目录 → 默认目录 → 此电脑根层**；相对路径按应用安装目录解析；无效路径安全回退不报错。

## 4. 标签页系统（Notepad++ 风格）

### 4.1 日常操作

| 操作 | 方式 |
| --- | --- |
| 切换标签 | 单击 / `Ctrl+PgUp`、`Ctrl+PgDn`（环形） |
| 最近使用快切 | `Ctrl+Tab`（反向 `Ctrl+Shift+Tab`），自绘面板列出全部标签 |
| 关闭当前 | `Ctrl+W` / 中键单击 / 双击标签 |
| 重新打开已关闭 | `Ctrl+Alt+T`（可连按，容量 10） |
| 固定 / 取消固定 | 右键 → 「固定 / 取消固定标签」（📌 前缀、排左、防关闭） |
| 双击标签栏空白 | 新建标签 |

### 4.2 右键菜单（批量关闭全集）

右键标签弹出菜单：

- **关闭**（固定标签置灰）
- **关闭其它所有** / **关闭左侧所有** / **关闭右侧所有**
- **关闭所有未修改**（已保存的）
- **关闭所有标签页**
- 在资源管理器中显示 / 在终端中打开
- 复制文件名 / 文件路径 / 所在目录

### 4.3 多选与批量关闭

1. **Ctrl+单击** 逐个增减选中；**Shift+单击** 连选区间（选中的标签显示主题强调色）。
2. 在选中标签上**右键** → 「关闭选中的 N 个标签页」（另有「取消多选」）。
3. 涉及未保存文档时弹**汇总确认**：**全部保存 / 全部不保存 / 取消**；「全部保存」中任一次另存被取消则整批中止、不动任何标签。
4. 固定标签不参与多选与一切批量关闭。
5. 「文件 → 关闭所有标签」与右键「关闭所有标签页」同语义。

## 5. 编辑与格式化

### 5.1 行内格式（悬浮命令栏 / 快捷键）

| 格式 | 快捷键 | 语法 |
| --- | --- | --- |
| 加粗 | `Ctrl+B` | `**文字**` |
| 斜体 | `Ctrl+I` | `*文字*` |
| 下划线 | `Ctrl+U` | `<u>文字</u>` |
| 删除线 | | `~~文字~~` |
| 高亮 | | `==文字==` |
| 行内代码 | `Ctrl+Shift+K` | `` `文字` `` |
| 链接 | `Ctrl+K` | `[文字](url)` |

- 全部为**开关式**：对已格式化文字再次执行即取消。
- 对裸文字加粗/斜体时自动**并入紧邻同标记壳**（`**已加粗**和普通` → 加粗「和普通」→ `**已加粗和普通**`），不产生冗余标记。

### 5.2 块级结构

- 标题：`Ctrl+1..6`；再次执行取消。支持 **h1~h6 居中**（悬浮栏 ⇔ 按钮）。
- 列表：有序/无序/任务清单，Tab / Shift+Tab 缩进嵌套。
- 引用块 `>`：支持内嵌列表、代码块、表格、图表。
- 脚注 `[^1]`、定义列表、分隔线 `---`。
- 斜杠菜单：行首输入 `/` 唤起全部块类型；命令面板 `Ctrl+Shift+P`。

### 5.3 撤销与安全

- `Ctrl+Z` / `Ctrl+Y`；进入源码态整体改写会**清空撤销/重做栈**（防止重做把内容静默覆盖回旧版）。

## 6. 表格

- 插入：`Ctrl+Shift+T` / 工具栏 / 斜杠菜单。
- 编辑：单元格直接输入；`Tab` 跳格；行尾 `Enter` 换行。
- **拖选**多个单元格 → 悬浮栏批量加粗/斜体/高亮/对齐/清空。
- 右键：合并 / 拆分单元格、行列增删、对齐、清空内容。
- 列宽拖动调整；`+` 按钮快速追加行列。

## 7. 图片、图表与公式

### 7.1 图片

- 复制粘贴 / 拖拽 / 右键插入；默认存到文档同目录 `assets/`，可选**内嵌 base64**（单文件分发）。
- 右键图片：切换存储方式、复制、替换、删除。

### 7.2 Mermaid 图表

- ```` ```mermaid ```` 围栏书写源码，自动渲染流程图 / 时序图 / 甘特图等。
- **单击图表**进入源码编辑（含引用块内图表），保存即回写原围栏，不改坏周边内容。
- 图表主题：设置 → 外观 → 图表主题（可跟随界面主题）。

### 7.3 数学公式（KaTeX）

- 行内 `$E=mc^2$`；独立公式块 `$$...$$`。
- 导出 HTML/PDF 自动内嵌公式样式。

## 8. 模板与片段

- 内置模板：斜杠菜单「插入模板」或工具栏（会议记录、周报、E-R 图等）。
- **自定义模板**：文件 → 设为模板文件；设置 → 模板管理（名称 ≤10 字，容量 3，可排序）。

## 9. 设置中心

设置（`Ctrl+,`）分页：**通用 / 外观 / 编辑 / 快捷键 / 模板 / 高级**。

- 通用：启动行为（欢迎页 / 上次文件 / 指定文件夹）、文件列表默认目录。
- 外观：六套界面主题、字号、图表主题。
- 编辑：打字机模式、专注模式、自动配对、emoji 补全、段首缩进、标题一居中。
- 快捷键：全表可视化改键（含本手册第 4、5 章全部项）。
- 高级：代码块行号 / 着色风格、默认代码语言、检查更新。

## 11. 故障排查与帮助

- **误关标签** → `Ctrl+Alt+T` 找回。
- **工具栏不见了** → 左缘 `»` 或 `Ctrl+Shift+B`。
- **草稿恢复** → 启动时自动提示未命名崩溃草稿。
- **检查更新 / 复制诊断信息 / 关于** → 「帮助」菜单。
- 本手册：**帮助 → 使用手册**（可随时查阅、滚动浏览）。
