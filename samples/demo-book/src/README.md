# mdEditor 书籍模式示例手册

欢迎使用 **mdEditor** 的「书籍模式」（BOOK-1）示例书籍。

本书用于验证以下功能：

- 侧栏「书籍」页签渲染目录树（Part / 章节 / 分隔符）
- 点击章节在编辑器内打开（惰性加载，不预读正文）
- 章节间的相对 `.md` 链接在编辑器内跳转（不弹浏览器）
- 右键新增 / 重命名 / 删除章节并写回 `SUMMARY.md`
- 同级拖拽重排章节并写回
- 上一章 / 下一章导航

## 快速开始

请按以下顺序阅读：

1. 先读 [安装](getting-started/installation.md) 了解环境要求。
2. 再看 [配置](getting-started/configuration.md) 调整偏好。
3. 进入 [排版与格式](guide/formatting.md) 学习行内格式。
4. 最后阅读 [书籍模式详解](advanced/book-mode.md) 理解本功能实现。

> 提示：本书还包含一个 [超大章节（性能测试）](large-chapter.md)，用于验证 3000 页级大书籍的渲染性能。
