# 书籍模式详解

本书本身就是一个 mdBook 结构，用于演示「书籍模式」。

## 目录结构

一本 mdBook 至少包含：

- `book.toml`：书籍元信息（标题、语言、作者等）
- `src/SUMMARY.md`：目录索引（书籍的灵魂）
- `src/` 下的各章节 `.md` 文件

## 设计约束

mdEditor 的书籍模式**只解析 SUMMARY.md 的目录索引**，绝不预读章节正文。
章节正文在「点击时惰性加载」，因此可以支撑 3000+ 页的超大型书籍，
不会因为书籍庞大而卡顿。

## 实现要点

- 侧栏第三页签「书籍」由 `BookTree` 渲染
- 相对链接统一经 `mdeditor://open?path=` 桥接，在编辑器内跳转
- 双向编辑（新增 / 重命名 / 删除 / 拖拽）写回 `bookmode.write_summary`
- `open_book_link` 对所有 md 文档通用，不局限于书籍

## 操作指南

- **打开书籍**：文件菜单 → 打开书籍… → 选择书籍根目录（含 `book.toml` 或 `src/SUMMARY.md`）
- **跳转**：点击目录树中的章节
- **导航**：文件菜单 → 上一章 / 下一章
- **编辑目录**：右键章节节点，可打开 / 重命名 / 删除 / 新增子章节 / 新增同级；同级可拖拽重排
