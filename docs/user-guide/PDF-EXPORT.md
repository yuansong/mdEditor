# PDF 导出最佳实践 · PDF Export Best Practices

> mdEditor 的 PDF 走 WebEngine 打印管线，并对**中文阅读习惯**做了专门优化。本文讲默认值为何这样设、怎么调、以及整本书导出如何保持一致。

---

## 一、开箱即用的「最佳默认」

从 v3.48.38 起，PDF 导出提供经过调校的**美观默认参数**，无需手动调即可产出符合中文阅读习惯的 PDF：

- **强制白底**：无论编辑器用什么主题，导出 PDF 一律白底黑字，避免深色主题把正文导成「黑底白字」的阅读灾难。
- **行间距 0.8 起**：比纯 1.0 更紧凑、比 1.5 更省纸，兼顾可读与篇幅；可改，但默认已是兼顾值。
- **合理页边距**：上下左右留白适中，正文宽度舒适。
- **H1 分页**：一级标题自动另起一页，章节结构清晰（长文档利器）。
- **图片自适应**：图片按页宽缩放，不溢出、不变形。

> 设置项里提供**「还原默认设置」**按钮：调乱了点一下回到最佳默认。

## 二、常用微调

| 设置 | 建议 | 说明 |
|---|---|---|
| 纸张尺寸 | A4（默认） | 国内通用；海外可换 Letter |
| 方向 | 纵向 | 技术文档纵向即可 |
| 四边距 | 默认 | 想更紧凑可整体减小 |
| 缩放 | 100% | 内容偏大时降到 90%~95% |
| 行间距 | 0.8（默认） | 想要更通透可升到 1.0~1.2 |
| H1 分页 | 开（默认） | 关掉则连续排版 |
| 图片适应 | 开（默认） | 关掉按原尺寸 |
| 强制白底 | 开（默认） | **强烈建议保持开启** |

## 三、单文件 vs 整本书，效果一致

- **单文件导出 PDF**：菜单「文件 → 导出 → PDF」。
- **整本书导出 PDF**：在书籍视图，「书籍 → 导出整本 PDF」。两者共用同一套默认参数与渲染逻辑，**默认效果保持一致**（同样强制白底、同样行间距、同样 H1 分页）。

> 实践建议：先用单文件调到满意，再整本导出，体验一致、无需重调。

## 四、进阶通道

- **pandoc 通道**：在「AI 连接 / 系统设置」配好 pandoc 路径后，docx / EPUB 导出优先走 `pandoc`（支持 `gfm+tex_math_dollars --toc`）。
- **PDF 书签**：依赖 `pypdf`，缺它 PDF 仍可导出但无书签；装了 `pypdf` 会按标题写入 PDF 书签，便于导航。
- **HTML 单文件离线**：若想要「可分享、零依赖」的版本，选 HTML 导出（KaTeX 字体 base64 内嵌、图表转静态 SVG、本地图片转 data URI，零 CDN）。

---

## 五、踩坑提醒

- 深色主题下务必保持「强制白底」开启，否则正文可能导出成反色。
- 超大图片可能撑破版心，开启「图片适应」即可。
- 复杂表格（合并 / 列宽）以 HTML 存储，PDF 渲染由 WebEngine 忠实还原，无需特殊处理。
