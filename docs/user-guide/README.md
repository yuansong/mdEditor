# 用户手册 / User Guide

mdEditor 的完整用户手册**随应用分发，不在此仓库以独立 Markdown 单独维护**，以避免内容重复与版本漂移。

- **手册源文件**：[`../../src/使用手册.md`](../../src/使用手册.md)
- **在应用中打开**：启动 mdEditor 后，通过菜单「帮助 → 使用手册」或按 `F1`，即可在编辑器内直接查看。

如果你需要把手册导出为独立文档（PDF / Word / HTML），可在应用内使用导出功能，或直接参考上述 `src/使用手册.md` 源文件。

> 提示：本目录仅作为手册入口索引；真正的手册内容由应用代码与 `src/使用手册.md` 统一维护。
