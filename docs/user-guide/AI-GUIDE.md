# AI 接入指南 · AI Setup Guide

> mdEditor 的 AI 能力是**写作闭环的内建功能**，不是外挂插件；默认**本地优先、按需上云**，密钥与文本始终由你掌控。本文讲怎么接、怎么用、以及隐私边界。

---

## 一、两种接入方式

| 方式 | 说明 | 需要密钥？ |
|---|---|---|
| **本地 Ollama（推荐先试）** | 在本机跑开源模型，完全离线、零费用 | 不需要 |
| **云端 BYOK（15 家）** | 自带各家 API Key，按需调用 | 需要 |

打开「工具 → 系统设置 → **AI 连接**」页：
- 默认已指向本地 Ollama；若本机装了 Ollama 且拉取了模型，启动后自动检测可用模型。
- 选云端厂商后，填入对应 API Key（存储在系统凭据库：Windows Credential Manager / macOS Keychain / Linux Secret Service），**不写进文档、不上云**。

已内置的云端厂商（示例）：OpenAI、DeepSeek、通义千问、智谱 GLM、Kimi、Gemini、Azure、OpenRouter、硅基流动、MiniMax、百川、Mistral、Together 等，外加「自定义 OpenAI 兼容端点」。

### 本地 Ollama 快速起步

```bash
# 1) 安装 Ollama（见 https://ollama.com）
# 2) 拉一个中文友好的模型，例如：
ollama pull qwen2.5:7b
# 3) 启动 Ollama 服务（默认 11434 端口），回到 mdEditor「AI 连接」页选 Ollama 即可
```

> 没网也能用：本地 Ollama 推理 + 本地语义检索，整条链路可在纯离线环境跑，适合政企内网 / 无网写作。

## 二、怎么用

### 1) 右键「AI 优化」（语义级改写）
- **正文选区**：选中文字 → 右键 → 「AI 优化」→ 润色 / 精简 / 扩写 / 纠错 / 翻译 / 改语气 / 选中提问。
- **整篇文档**：在文件标签或文件列表右键 → 「AI 优化」（整篇级提供六类动作）。
- 每个动作是独立预设提示词，可在「AI 连接」设置里**自定义**菜单项与提示词。

### 2) 片段级可控采纳
AI 改写结果以**片段 diff** 呈现，可**逐处采纳或回退**，全程 `Ctrl+Z` 可撤销，**绝不无声覆盖原文**。

### 3) 流式问答面板（侧栏 AI 助手）
- 支持流式增量生成；生成中按 `ESC` 中止；回答一键复制 / 插入。
- **上下文约束**：默认只依据当前文档上下文作答与改写，抑制模型臆造。

### 4) 本地语义检索
`semsearch` 用 TF-IDF + 同义词实现**零依赖语义搜索**，与跨文件关键词检索互补，离线即可做近义召回（见主 README「查找 · 导航」）。

---

## 三、隐私边界

- 本地 Ollama：文本与生成**不出本机**。
- 云端 BYOK：文本会按你选择的厂商发往对应 API；密钥只存本机凭据库。
- 不做订阅、不做遥测、不上传你的文档。

---

## 四、常见问题

- **填了 Key 没反应？** 确认「AI 连接」页模型已选对应厂商、Key 正确、网络可达；看「帮助 → 复制诊断信息」里的 AI 日志。
- **Ollama 检测不到模型？** 确认 `ollama serve` 在跑、模型已 `ollama pull`、端口未被防火墙拦。
- **能换默认模型吗？** 能，在「AI 连接」页切换；文档级与选区级可分别配置。
