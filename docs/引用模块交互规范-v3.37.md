## 一、现状退出路径全列举（问题 1）

引用是**渲染态常驻编辑**（`blockquote[contenteditable=plaintext-only]`，1992/2021-2054），不存在「进入/退出编辑态」的分界，因此「退出」只有一种含义：**光标离开引用，或引用本身转段落**。现有 9 条路径：

| # | 路径 | 触发 | 实际行为（实证） | 评价 |
|---|---|---|---|---|
| 1 | 空末行回车（= 连续两次回车） | 行尾 Enter ×2 | **缺陷 QUO-8**：引用整体切入源码态（`blk raw-edit t-quote`，显示字面 `> 引文甲行`），**无新段落**（_m101c 实证） | ❌ 落点错误，改（见第二节） |
| 2 | 末尾空行 Backspace | 空行行首退格 | **缺陷 QUO-9**：整块拍平转段落（`raw=['引文丙行']`，`raw-edit t-p`）；多行引用同样全拍平 | ❌ 与「空行在中间仅删空行保引用」（4520-4528）同函数内自相矛盾 |
| 3 | 非空行行首 Backspace（深度 1） | 行首退格 | 单行：整块转段落（`raw-edit t-p`，Typora 一致 ✓）；多行：**整块拍平**（F1 实证 `行一\n行二` 全部脱离引用） | ◐ 单行保留；多行改「仅当前行脱离」 |
| 4 | 嵌套行首 Backspace（深度 ≥2） | 行首退格 | 退一级嵌套，引用保留（QUO-3，B3 PASS） | ✅ 保留 |
| 5 | Shift+Tab | 渲染态按键 | 逐级减前缀；单行退光即转段落（F2）；嵌套降一级保引用（F3） | ✅ 保留 |
| 6 | 方向键跳出 | Up/Left 行首、Down/Right 末尾 | 光标跳上/下一块（`editIdx` 切换），引用保持渲染态（C1 PASS） | ✅ 保留 |
| 7 | 点击引用外 | mousedown 其他块 | 失焦，引用保持渲染态、raw 不变（C3 PASS） | ✅ 保留 |
| 8 | 源码态空引用行回车 | raw-edit 下 Enter | 退出 + 其后新建空段落（`splitBlock` 3810-3818，QUO-3）——**正确范式** | ✅ 保留（渲染态应对齐它） |
| 9 | 块菜单「转为段落」 | ⠿ / Ctrl+/ / 右键 | 整块转段落 | ✅ 保留 |

**缺失项**：①Esc 无任何处理（C2 实证）——建议补「Esc = 失焦退出编辑，内容不动」，低优先级；②点击外部已是事实退出，无需改；③核心缺口不是「少一条路」，而是**主路径（双回车）落点错误**——见下。

## 二、双回车异常：预期行为与根因（问题 2）

**预期（规范定义 E1）**：行尾第一次回车 → 引用内新增空行（可见换行）；空末行第二次回车 → **引用保留渲染态 + 其后新建空段落 + 光标落新段落行首**。

**实证（_m101c A2）**：`raw=['> 引文甲行']`、块 0 类名 `blk raw-edit t-quote`、`editIdx=0`、无新块——第二次回车把引用**本块**切进源码态，用户眼前出现字面 Markdown 文本。

**根因（editor.html 4468-4479，渲染态 Enter 空末行分支）**：
1. 写回用 `quoteLinesFromDom`（带 `> ` 前缀）→ 块仍是引用，这半步正确；
2. 收尾却调 `enterEdit(i, 1e9)` → 把**同一块**强制切源码态——这正是「怪异」的来源；
3. 缺少「`splice(i+1, 0, '')` 新建段落 + `enterEdit(i+1, 0)`」两步。

**对照正确范式**：同文件里已有两处现成样板——源码态退出 `splitBlock` 3810-3818、列表空项退出 4585-4601，均为「保原块 + 后插空段落 + `enterEdit(i+1, 0)`」。修复即把 4476-4478 改成该三步。

**附带规范决策（嵌套空行回车）**：`splitBlock` 3804 注释自称「逐级退出」但实现是直接退出（`>> ` 空行回车直接出块）——注释与实现不符。规范定为：**空行回车先降一级嵌套，顶层空行回车才退出**（与行首 Backspace / Shift+Tab 的渐进语义一致，同 Typora）。若开发嫌成本高，至少把注释改为与实现一致。

## 三、内容类型限制（问题 3）：引用内不支持标题

**现状（实证）**：引用内标题渲染**不一致**——首行 `> # 标题行` 渲染为 `.qblk` 富块内 h 标签（不可编辑，D1）；中部 `> # 粘贴来的标题` 渲染为**字面文本**（D2，`qblk=0`）。键入手打无法产生（plaintext-only 天然安全）；粘贴经 `pasteMdInto` BLOCKQUOTE 分支（5231-5243）原样插入，正是 D1/D2 分裂的来源。

**规范定义**：
1. 引用内**不支持标题**（h1-h6）。理由：①渲染层两条路径已不一致，证明它从未是正式能力；②qblk 富块不可编辑，标题唯一的编辑方式是双击转源码，体验断崖；③标题的导航/大纲语义与引用的行模型冲突；④收益低于一致性成本（Typora 支持但 mdEditor 引用是行模型 + qblk 混合架构）。
2. **输入**：无需处理（plaintext-only 键入不含标记）。
3. **粘贴**：`pasteMdInto` BLOCKQUOTE 分支在插入前剥除行首 `#{1,6}\s`，标题降级为普通段落文本。
4. **渲染（历史文档）**：`quoteRenderHtml` 的内联富块判定把 h1-h6 与 'p'/'text' 同列为普通行，`> # x` 统一渲染为文本。**raw 保留原样，不迁移存储**（存储形态不漂移原则）。
5. 列表 / 代码块（QUO-5 渲染态编辑）/ 表格 / 图片 / 图表 / 公式：维持 qblk 富块现状；是否开放其余富块的渲染态编辑**不在本规范扩大**，另立专项。

## 四、提示与可发现性（用户追问）

引用的操作（双回车退出 / Backspace 降级 / Tab·Shift+Tab 嵌套）**全靠用户试出**，与 TBL-F3（块菜单可发现性）同族。建议三层（成本从低到高）：

| 方案 | 内容 | 机制复用 | 成本 |
|---|---|---|---|
| ①空行占位提示（**推荐首发**） | 引用末行为空时行内占位「回车退出引用 · Tab 嵌套 / Shift+Tab 减少」 | `data-ph` 占位机制（fnedit/dd、TBL-F2 空单元格两处先例）；只在空行显示、零干扰 | 半天 |
| ②一次性 toast | 首次进入引用编辑提示「连续两次回车退出引用；Tab 嵌套」 | QSettings 记已读（mmdtheme 命令通道同款思路） | 半天 |
| ③帮助面板收录 | 本文档第五节操作清单入帮助 | 既有帮助面板 | 1 小时 |

不建议常驻 tooltip / 浮层提示：引用是纯键盘流，浮层遮挡正文得不偿失。①②互补——占位提示时机最准（正要退出的那一刻），toast 覆盖首次认知。

## 五、完整操作清单（规范正文）

✅=现状符合；❌=缺陷（附编号）；➕=新增规范条文。

**进入引用**
1. ✅ 段落源码态行首输入 `> `/`> 文字`，提交后重建为引用。
2. ✅ `/` 菜单「引用」（8480）。
3. ✅ 块菜单「转为引用」（引用块自身隐藏该项，QUO-5）。
4. ✅ 粘贴 `>` 开头文本到段落 → 整块成引用（行模型重建）。

**引用内编辑与换行**
5. ✅ 点击渲染引用即编辑（plaintext-only 所见即所得，无源码态切换）。
6. ✅ 非空行回车 → 当前行后新增同前缀行（Typora 式续写，4481-4499）。
7. ✅ 行内格式（粗斜高亮码链）经 FMT-8 按 `> ` 行模型写回（4095-4108）。
8. ➕ **中间空行回车**：继续新增空行（不退出；退出仅认末行空行）。

**嵌套**
9. ✅ Tab / 多行选区 Tab → 整段批量加一级（QUO-4）。
10. ✅ Shift+Tab → 减一级；行退光后单行即转段落（F2）。
11. ✅ 嵌套引用渲染为嵌套 blockquote，深度按 `> ` 个数（1649-1725）。

**退出（全部路径，规范定义）**
12. ❌ **E1 主路径**：末行空行回车 → 引用保留 + 其后新建空段落 + 光标落段落（QUO-8 修复）。
13. ❌ **E2 撤销**：末行空行 Backspace → 仅删空行、光标回上行行尾，引用保留（QUO-9 修复）。
14. ◐ **E3 渐进**：行首 Backspace / Shift+Tab 每次退一级；顶层行退光时——单行整块转段落（✅）；多行**仅当前行脱离**成段落、其余行保持引用（❌ 现整块拍平，随 QUO-9 同批改）。
15. ✅ **E4 光标离开**：方向键到上/下边界跳出；点击引用外失焦；引用保持渲染态、内容不动。
16. ➕ **E5**：Esc = 失焦（光标清除、内容不动），不删除、不转段落。
17. ✅ 块菜单「转为段落」= 显式整块退出。
18. ➕ **嵌套空行回车**：先降一级，顶层空行回车才退出（`splitBlock` 3804 注释同步修正）。

**内容类型**
19. ➕ 标题（h1-h6）**不支持**：粘贴剥 `#` 降级、渲染统一按普通行、raw 不漂移（第三节）。
20. ✅ 列表 / 表格 / 图片 / 图表 / 公式：qblk 富块（不可直接编辑，双击转源码态）。
21. ✅ 代码块：qblk + 渲染态编辑（QUO-5）。
22. ✅ 引用内 `/` 插入（表格/代码/图片/图表/公式/分割线）按光标行后追加（QUO-2）。
23. ✅ 粘贴围栏/表格语法 → quoteAppendBlock 生成内嵌富块（QUO-6）。

**快捷键与全局**
24. ✅ 行内格式快捷键（Ctrl+B/I 等）在引用渲染态生效（QUO-1 统一方案）。
25. ✅ 撤销 / 重做 / 快照覆盖引用块。
26. ➕ 空行占位提示 + 首次 toast（第四节①②）。
