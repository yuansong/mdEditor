# mdEditor 主界面重设计方案（UI-SPEC · v3.39.14）

> 设计师：UI 设计师专家 · 日期：2026-10-11 · 状态：**设计方案稿，未改任何代码**
> 风格基线：**现代经典桌面风**（用户拍板）——Win10/11 桌面软件质感，菜单栏+工具栏+状态栏结构，浅灰界面，对标 Notepad++ / VS Code / Office 2016+。
> **R2 修订（2026-10-11，用户反馈）**：① 撤销「格式」菜单——格式化与段落样式组**沿用原设计**（悬浮格式栏 + 斜杠菜单 + 快捷键，不设菜单，v3.31 决策维持有效）；② 模式切换（写作/源码/分屏）从工具栏移至**菜单栏同一行右端**。
> **R3.5 修订（2026-10-11，用户反馈）**：③ 左侧**竖向工具栏保留**（不改为横向），按钮项可重排——新增插入表格/插入图片两钮，原「模式循环钮」移除（由菜单栏右端分段钮承担）；④ 侧栏开关「«」文本钮统一为线性侧栏面板图标。
> **R4 修订（2026-10-11，用户反馈 + 参考截图）**：⑤ 左工具栏撤去插入表格/图片两钮，设置钮上移，新增**历史版本**钮；⑥ 菜单栏右端扩为**模式与状态区**（参照 Typora 同区）：专注 / 打字机快捷开关 + 写作/源码/分屏分段钮 + 设置直达 + 「✓ 已保存」状态灯。
> **R5 修订（2026-10-11，用户反馈去冗余）**：⑦ 菜单栏右端撤去「✳ 设置」（左工具栏齿轮 + 工具菜单已双入口）与「✓ 已保存」（状态栏保存格已承载）——Typora 放这两者是因为其无左工具栏/无状态栏，本方案均有，属纯冗余。右端定名**视图状态区**：仅专注 / 打字机 / 模式分段钮，保持「视图行为」语义纯净。
> **R6 修订（2026-10-11，用户拍板）**：⑧ **撤销「插入」菜单**——插入统一走斜杠菜单「/」（11 项、拼音过滤）+ 块菜单，菜单栏收敛为 **5 项**；与 v3.31「格式不设菜单」同一极简逻辑。**附硬性发现性补偿**：① 空行/空文档 placeholder「输入 / 插入表格、图片、图表…」；② 新文档首次一次性气泡提示；③ 使用手册与 F1 快捷键一览保留斜杠菜单章节。竞品参照：Obsidian 无插入菜单、纯斜杠命令 + 提示即成立。
> **R7 修订（2026-10-11，按《对比分析》改进建议落实）**：⑨ 效果图新增**深色主题演示切换**（墨夜向令牌映射）、**专注模式交互演示**（左右栏隐藏 + 右端视图状态区淡出）、**悬浮格式栏高保真示意**、**窄窗断点响应演示**（<1240px 侧栏收窄 200px）、历史版本钮防误触 tooltip；⑩ 规格新增 **3.4 性能红线**（placeholder 惰性化 / 字数节流 / 状态单向更新）。
> 功能底稿：《主界面功能与菜单全量清单-v3.39.14.md》（本方案覆盖其 A~M 全部 13 类功能，无删减、仅重组织）。

## 一、现状分析

### 1.1 核心功能清单（重设计输入，13 类）

| 类别 | 核心能力 | 现状入口问题 |
|---|---|---|
| A 文档管理 | 多标签、保存组、最近文件、草稿恢复 | 文件菜单 19 项过长，混杂导出/版本/归档 |
| B 格式编辑 | 粗斜下删高/行内码/链接/清除 | **13 个格式命令无菜单**（v3.31 决策），纯靠快捷键+悬浮栏，发现性差 |
| C 块级转换 | 标题/列表/引用互转、移动复制 | 仅块菜单（Ctrl+/），菜单栏无入口 |
| D 插入元素 | 斜杠菜单 11 项 | 菜单栏无插入菜单，鼠标用户需先学「/」习惯 |
| E 表格 | Office 级行列/合并/对齐 | 入口完善（保持） |
| F 代码块 | 顶栏语言/风格/行号/换行 | 入口完善（保持） |
| G 图片管理 | 双模式存储/裁剪/转存 | 块菜单完善；「迁移内嵌图片」埋在文件菜单 |
| H 图表公式 | Mermaid 7 类 + KaTeX | 插入依赖斜杠菜单二级 |
| I 视图模式 | 写作/源码/分屏 | 视图菜单混 8 类异质项（模式/开关/标签导航/折叠/全屏） |
| J 查找导航 | 查找替换/全局搜索/大纲/面板 | 入口合理（保持） |
| K 导出交付 | HTML/PDF/Word/EPUB/复制为HTML | 5 项平铺文件菜单中段 |
| L 版本容灾 | 历史版本/快照/草稿/归档 | 3 项散在文件菜单尾部 |
| M 设置帮助 | 系统设置四页/快捷键自定义 | 独立「设置」菜单仅 2 项，单薄 |

### 1.2 结构性问题（重设计动机）

1. **文件菜单过载**：19 项混 4 类异质功能（文件生命周期/导出/版本/容灾）；
2. **格式与插入零菜单入口**：鼠标型用户与新手无法发现 Ctrl+E / 斜杠菜单能力；
3. **视图菜单是大杂烩**：模式、UI 开关、标签导航、缩放缺失、专注类、全屏混排；
4. **工具栏信息量低**：左竖条仅 8 钮且全为文件级，与「格式编辑器」定位不匹配；
5. **无状态栏**：字数/行列/保存态无处安放（写作软件基本盘，Typora/Word 均有）。

## 三、信息架构（IA）与菜单组织

### 3.1 顶层结构：5 菜单 → 5 菜单

```
旧：文件(19项) 编辑 格式(隐藏) 视图(杂烩) 设置(2项) 帮助
新：文件 编辑 视图 工具 帮助      （5 项，经典桌面标准排布；格式/插入均不设菜单）
```

重组规则（每条旧功能都有唯一新家，**零功能删减**）：

| 新菜单 | 收纳内容（来源） | 组织原则 |
|---|---|---|
| **文件(F)** | 新建/打开/文件夹/最近 + 保存组 + 关闭组 + **导出(子菜单，5 项自文件菜单收拢)** + 退出 | 只留文档生命周期；导出=「文件的去向」，收拢为子菜单（Word/WPS 惯例） |
| **编辑(E)** | 撤销重做 + 剪贴板 4 + 查找/替换/全局搜索/转到行 + 块菜单 + 命令面板 | 基本沿用现状 |
| **视图(V)** | 三模式 + UI 开关（侧栏/工具栏/状态栏）+ **缩放组（新增）** + 标签导航 3 项 + 打字机/专注 + 全屏 + 折叠/展开标题（维持原归属） | 纯视觉与窗口行为 |
| **工具(T)** ★新增 | 历史版本/立即留档 + 迁移图片/归档工作区 + 系统设置/快捷键设置 | 版本容灾与批量工具自文件菜单迁入；「设置」菜单取消并入（经典「工具→选项」惯例），**工具栏齿轮保留直达** |
| **帮助(H)** | 手册/快捷键一览/检查更新/诊断/关于 | 不变，恒居最右 |

**格式化与段落样式（R2 定稿）：不设格式菜单**。沿用原设计三通道——选中悬浮格式栏（B/I/U/S/高亮/码/链接/清除）、斜杠菜单与块菜单（段落样式）、快捷键（Ctrl+B/I/E、Ctrl+1~3/0 等）全部保留不动。

**插入（R6 定稿）：不设插入菜单**。统一走两通道——斜杠菜单「/」（11 一级项，拼音/关键字过滤）+ 块菜单（Ctrl+/）；Ctrl+Shift+T（表格）等插入类快捷键全部保留。**发现性补偿为硬性配套**（缺一则方案不成立）：

| 补偿 | 形式 | 时机 |
|---|---|---|
| 空行 placeholder | 空块/空文档灰字提示「输入 / 插入表格、图片、图表…」 | 常显（空状态） |
| 首次引导气泡 | 「试试输入 / 唤起插入菜单」一次性气泡 | 新文档首次空白时，仅一次 |
| 文档化 | 使用手册 §插入、F1 快捷键一览保留斜杠菜单章节 | 常显 |

**左侧竖向工具栏（R4 定稿）：保留竖列**：

| 位置 | 按钮 | 相对原设计的变化 |
|---|---|---|
| 顶部 | 侧栏开关 | 图标统一：原「«」文本钮 → 线性侧栏面板图标（与工具栏图标体系一致） |
| 文件组 | 新建 / 打开 / 保存 | 不变 |
| 编辑组 | 撤销 / 重做 | 不变 |
| 查找 | 查找 / 替换 | 不变 |
| 版本 | 历史版本（Ctrl+Shift+H） | ★新增（自工具菜单前置的高频安全操作） |
| 底部 | 系统设置齿轮 | **上移**：紧随历史版本之后，不再单独沉底 |
| —— | ~~模式循环钮~~ | **移除**：模式切换改由菜单栏右端分段钮承担（单击直切，消除循环不可预期），视图菜单三模式单选项保留作镜像，状态联动 |
| —— | ~~插入表格 / 插入图片~~ | **不进工具栏**（R4 撤销 R3.5 决定）：插入走插入菜单 + 斜杠菜单双通道即可 |

**菜单栏右端 · 视图状态区（R5 定稿，参照 Typora 同区设计并去冗余）**：

| 控件 | 形态 | 联动关系 |
|---|---|---|
| ◉ 专注 | 文字快捷开关（hover 高亮，激活态着色） | 与视图菜单「专注模式」互为镜像 |
| ≡ 打字机 | 文字快捷开关 | 与视图菜单「打字机模式」互为镜像 |
| 写作/源码/分屏 | 分段钮，单击直切 | 与视图菜单三模式单选项、状态栏模式格三处联动 |

**去冗余决策（R5）**：不放「设置」——左工具栏齿轮与工具菜单已是双入口；不放「保存状态」——状态栏保存格已承载。Typora 在此区放这两者是因为其既无左工具栏也无状态栏；本方案两者皆有，重复放置属入口膨胀。该区只保留**视图行为**（模式/专注/打字机），与左侧菜单（文档操作）形成「左操作、右视图」分区。

### 3.2 新旧映射对照（迁移清单）

| 旧位置 | 新位置 |
|---|---|
| 文件→导出 HTML/PDF/Word/EPUB/复制为 HTML（5 项平铺） | 文件→导出 ▸（子菜单） |
| 文件→历史版本/立即留档/归档工作区/迁移图片 | 工具菜单 |
| 文件→关闭标签/关闭所有/重开标签 | 文件菜单保留（关闭组） |
| 设置→系统设置/快捷键设置 | 工具→系统设置…/快捷键设置… |
| 斜杠菜单 11 项（仅「/」唤起） | **维持唯一插入通道**（不设插入菜单，R6 拍板）+ 空行 placeholder / 首次气泡发现性补偿 |
| 左工具栏「模式循环钮」 | 菜单栏右端「模式分段钮」（写作/源码/分屏，单击直切） |
| 工具→历史版本 | 左工具栏新增历史版本钮（菜单入口保留，双入口同源） |
| 视图→打字机模式 / 专注模式 | 菜单栏右端快捷开关（视图菜单保留作镜像） |
| 隐藏格式动作 13 项（无菜单） | **维持原设计**：悬浮栏/斜杠菜单/快捷键三通道，不设菜单（v3.31 决策保持有效） |
| （新增）状态栏开关、缩放 Ctrl+= / Ctrl+- / Ctrl+0 | 视图菜单 |

> ⚠️ **需要拍板的决策变化**（实施前与产品/开发确认，AGENTS.md 第十一节）：① 「设置」菜单取消并入工具菜单；② 左工具栏「模式循环钮」移除（改菜单栏右端分段钮，循环切换习惯用户可走视图菜单或分段钮）；③ **不设插入菜单**（R6 已拍板，实施时需同步落地空行 placeholder 与首次气泡两项补偿）。**v3.31「格式命令不设菜单」决策维持有效**；「折叠/展开标题」维持视图菜单原归属。快捷键一律不冲突不改（Ctrl+Shift+T 仍为插入表格等）。

### 3.3 关键取舍说明

- **为什么格式不设菜单（R2 拍板）**：格式化入口已三通道覆盖（悬浮栏零距离、斜杠菜单可过滤、快捷键高效），再设菜单属第四入口冗余；且「格式」菜单与现有 Observed 决策冲突，尊重既有设计。悬浮格式栏保持 PS-02 规格（沿现状保留）。
- **为什么插入不设菜单（R6 拍板）**：与格式决策同一极简逻辑，斜杠菜单（可过滤）+ 块菜单双通道已覆盖全部插入能力。**与格式的关键差异在发现性**——悬浮栏选中即见、Ctrl+B 是通用常识，而「/」是隐藏约定，故去掉菜单必须配套 placeholder + 首次气泡（见 3.1 补偿表），Obsidian 同模式验证可行。
- **为什么导出收子菜单而非移工具**：导出对象是当前文档，用户心智在「文件」；平铺使文件菜单过载，子菜单两全。
- **为什么模式切换放菜单栏右端**：写作/源码/分屏是全局视图状态，与文档操作无关，放菜单栏右端形成「菜单（文档操作）｜右侧（视图状态）」的经典分区；分段钮单击直切，消除旧循环钮「点一下不知道去哪」的不可预期性。

## 四、页面规格（PS）

### PS-01 主界面总览（效果图：`docs/ui-redesign/主界面效果图-PS01.html`，可点击展开菜单）

**目标**：一屏看清八区布局与全部菜单组织。
**布局**（上→下，R3.5）：

```
① 标题栏 34px   文档名 + 最小化/最大化/关闭
② 菜单栏 30px   文件 编辑 视图 工具 帮助 ｜…… 右端视图状态区：◉专注 ≡打字机 [写作|源码|分屏]
③ 工作区（三列）左1：左侧竖向工具栏 42px（侧栏开关|新建/打开/保存|撤销/重做|查找|历史版本|设置）
               左2：侧边栏 228px（文件列表/大纲页签 + 面包屑 + 列表）
               右：标签栏 32px + 编辑区
⑧ 状态栏 26px   消息区 | 写作 | 1,284 字 | 行12,列8 | 100% | ✓ 已保存
```

**交互**：
- 菜单：点击展开（非 hover 展开，经典 Windows 行为；打开一个菜单后移入其他菜单名才切换）、Esc/点击外部关闭、助记符 Alt+首字母；
- 菜单项：hover 高亮 `--accent-bg`；不可用项置灰不隐藏（与表格右键「动态隐藏」策略区分——菜单栏用置灰保持结构稳定，上下文右键用隐藏）；
- 模式分段钮（菜单栏右端）：写作/源码/分屏三段，单击直切（替代旧左工具栏「循环钮」，消除「点一下不知道去哪」的不可预期性）；与视图菜单三模式单选项、状态栏模式格三处状态联动；
- 专注 / 打字机快捷开关：单击切换，激活态着色提示；Esc 或再点一次退出（沿用现退出交互）；
- 侧栏开关：原「«」文本钮统一为**线性侧栏面板图标**（与工具栏图标体系一致，不再特殊化）。

### PS-02 编辑区浮层（沿现状保留，规格化）

| 浮层 | 触发 | 内容 | 状态反馈 |
|---|---|---|---|
| 悬浮格式栏 | 选中文字 | B I U S 高亮 码 链接 清除（+H1 居中切换）；图表/代码块/公式内只留删除块 | 尾部「标题 N，已选 M 字」；点击后选区不塌陷 |
| 斜杠菜单 | 空块输入 `/` 或 Ctrl+/ | 11 一级项（唯一插入通道，R6）；空行 placeholder 提示「输入 / …」 | 支持拼音/关键字过滤 |
| 块菜单 | Ctrl+/ 或块柄 | 块转换 + 复制/上移/下移/删除 | 按块类型动态显隐 |
| 表格工具栏 | 选中单元格/拖选 | 行/列/合并拆分/移动/对齐/清空 | 只显示当前可执行项（保持现策略） |
| 代码块顶栏 | 常显 | 折叠/语言/风格/行号/自动换行 | 行号、换行钮 title 即时反映开合 |

### PS-03 标签栏与状态栏

- 标签：📌固定（不可关闭、恒排左）· ● 未保存 · + 新建 · ▾ 溢出下拉；右键菜单 13 项保持现状（已对标 Notepad++，无改动）；
- 状态栏五格：消息区（toast 文案落地处，替代纯浮动 toast 的易丢失问题——**重要消息同时落状态栏**）｜模式（可点击循环切换）｜字数｜行列｜缩放（点击重置）｜保存态（✓ 已保存 / ● 未保存 / ⟳ 保存中）。

### PS-04 分屏/源码模式

布局不变（左源码右预览），差异仅：菜单栏右端分段钮高亮迁移 + 状态栏「模式」格同步；保存态仅由状态栏保存格承载（✓ 已保存 / ● 未保存 / ⟳ 保存中），状态栏模式格点击时给出「切回写作模式可用」提示（沿用现 toast 文案）。

### PS-05 关键状态反馈矩阵

| 场景 | 反馈位置 | 形式 |
|---|---|---|
| 保存成功 | 状态栏保存格 | ✓ 已保存（静默，无 toast） |
| 保存失败 | 状态栏消息区 + 对话框 | 红色错误文案 + 重试入口 |
| 打开文件 | 状态栏消息区 | 「已打开 · 路径」 |
| 格式应用（无视觉效果时） | 状态栏消息区 | 沿用现 toast 文案 |
| 固定标签后关闭尝试 | 状态栏消息区 | 「标签已固定，请先取消固定 · 文件名」 |
| 菜单项不可用 | 菜单内置灰 + 原因悬停提示 | tooltip 说明原因（如「无选区」） |

## 五、性能红线（3.4 · 实施必须遵守，源自对比分析建议 #3/#5）

| 红线 | 要求 |
|---|---|
| 状态唯一源 | 模式/专注/打字机以**模式管理器为唯一 state**，右端分段钮、视图菜单、状态栏均为订阅者，禁止双向广播刷新 |
| 字数统计 | 300ms 节流 + 仅统计活动标签；大文档（>1MB）降级为保存时刷新 |
| placeholder 空态判定 | **惰性检查**：仅挂 文档加载/块删除/撤销重做/光标换行 四个事件，禁止挂每次 input |
| 状态栏刷新 | 行列格跟随光标事件节流（~200ms）；保存态由保存流程主动推送，不轮询 |
| 首次气泡 | 一次性（QSettings 已读标记），显示 3s 自动淡出，不阻塞输入 |

## 六、可访问性与响应式

- 对比度：正文 15.2:1、次级 4.9:1，均 ≥4.5:1 ✅；快捷键灰字仅用于辅助信息 ≥11px；
- 点击区域：工具栏钮 28×28 + 2px 间隙（桌面标准，≥44px 为移动端要求，本项目为 Windows 桌面应用不适用）；
- 键盘全可达：菜单 Alt+助记符、菜单内方向键+Enter、全部快捷键保留且可在快捷键设置改；
- 不只靠颜色：未保存用「●」符号、固定用「📌」、保存态有文字标签；
- 断点行为（桌面窗口）：≥1280 完整布局；1024~1280 侧栏自动收窄至 200px；<1024 侧栏默认收起（边缘 » 展开钮沿用 TB-1 机制）；标签溢出永远走 ▾ 下拉（TAB-9 机制沿用）。
