## 二、失败组合汇总（3 个新缺陷，已登记清单 FMTB-7/8/9）

### FMTB-7：行内码壳内选区 → 所有行内格式静默无反应（用户报告 bug）

| 项目 | 内容 |
|---|---|
| 错误表现 | 选中行内代码内文字后点加粗/斜体/删除线/高亮，**界面无任何变化、无提示** |
| 复现步骤 | ①输入 `甲\`码乙\`丙`（码紧邻文字）；②选中码内「码」「码乙」或部分「乙」；③点加粗 → 无反应；斜体 → 无反应 |
| 关键边界 | 码两侧**有空格**时整选可正常外侧包裹（`甲 \`码\` 乙` ✅）；码**紧邻文字**时静默（`甲\`码乙\`丙` ❌） |
| 对照组 | strong/em 壳内选区 toggle/嵌套**全部正常**（S2 组），仅 code 壳异常 |
| 根因线索 | `wrapCodeSpanRaw`（editor.html:9089）`rs < pre.length → return false` 的失败路径 toast 未送达；选区落在 `<code>` 文本节点上时部分路径提前静默 return |
| 修复建议 | 整选一律走码外侧包裹（`rs < pre.length` 允许，`甲**\`码乙\`**丙` 语法合法）；部分选拒绝时确保 toast 送达（半天） |

### FMTB-8：多层叠加「重复粗体」产生游程交错 → 渲染丢格式（用户第二个案例）

| 项目 | 内容 |
|---|---|
| 错误表现 | 连续叠加格式后源码出现 `**<u>**\`文字\`**</u>**` 交错游程，渲染层格式丢失、出现空 `<u></u>`；用户案例最终源码 `*~~**<u>**\`一个可爱的\`**</u>**~~*` 渲染只剩 `<u>一个可爱的</u>` |
| 复现步骤（U1 四步，居中 h2） | ①`<h2 align="center">1. 我是一个可爱的人</h2>`；②选「一个可爱的」→ 代码；③→ 加粗；④→ 下划线；⑤**再点加粗** → 游程交错（破坏点在第⑤步） |
| 影响范围 | 居中与破坏无关（居中往返专项 14/14 全过）；任意宿主（段落同样可复现）；叠加 ≥3 层后点重复格式即触发 |
| 根因 | `wrapSelection` 的 FMT-11 标签壳外推循环（3811-3836）在 `**<u>**\`码\`**</u>**` 上判「未包裹」→ 普通包裹把 `**` 插进 `<u>` 内侧；**FMTB-5 的区间内部标记守卫被外推后的新区间绕过** |
| 修复建议 | 区间内部标记守卫纳入标签壳/码壳（区间内不成对游程或 `<` 即拒绝 + toast）；或外推要求左右层对称（1 天） |

### FMTB-9：跨界选区（壳内+壳外）拒绝应用但无 toast（FMTB-5 保守修的 UX 缺口）

| 项目 | 内容 |
|---|---|
| 错误表现 | 选区横跨已格式化边界时点格式**无反应、无提示**（拒绝本身正确——不再产出脏 raw，但用户不知道为何失效） |
| 复现步骤 | ①输入 `甲**乙**丙`；②选「甲乙」或「乙丙」（横穿粗体壳边界）；③点加粗 → 静默无反应 |
| 影响范围 | 任意壳型（strong/em/code）；模糊测试 49 处静默报警绝大多数属此类 |
| 修复建议 | 静默 return 点补 toast「选区包含已有格式边界，请选格式连续的文字」（2 小时） |

3 种子（42 / 20261007 / 777）× 55 步：随机注入（空/超长 400 字/HTML 字符/预置格式/码混排）× 随机选区 × 随机动作（6 格式 + clearfmt）：

> 注：#49 最小复现（`~~纯文本段落第二~~\`份\`` 选「二」套高亮 → 无变化静默；同输入去掉码后正确 `~~纯文本段落第==二==~~`）进一步印证 **码的存在使映射/守卫链路失效**，与 FMTB-7 同族。

## 四、旧缺陷回归确认

- FMTB-5（区间内横穿标记交错）：修复**基本生效**——段落跨界选区不再产出脏 raw（变静默拒绝，反馈缺口登记 FMTB-9）；但 `**<u>**` 多层结构有漏网（FMTB-8）；
- FMTB-6（350ms 防抖竞态）：本轮未复现失效（修复生效迹象），高负载场景留观察；
- FMTB-1/2/4（单元格 occ / 码内守卫 / 跨块文案）：单元格与码内守卫未回归。

| 编号 | 优先级 | 工作量 | 理由 |
