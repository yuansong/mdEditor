## 六、建议的防漂移机制

1. **单一出处**：功能细节只写在《使用手册》，README 只放概览、快速开始、仓库/许可信息。
2. **版本口径**：`APP_VERSION` 是唯一版本真值，文档页脚引用而非硬编码在标题。
3. **发布前检查**：改代码 → 同步 CHANGELOG + 手册 → 再打包（与你现有流程一致）。
4. **定期复核**：评分榜 / 竞品调研类文档标注有效期，到期重跑。
