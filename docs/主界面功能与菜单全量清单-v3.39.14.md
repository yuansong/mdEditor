## 第一部分 界面骨架总览

```
┌────────────────────────────────────────────────────────────┐
│ 菜单栏：文件 编辑 视图 设置 帮助                              │
├──┬──────────┬──────────────────────────────────────────────┤
│左│ 标签栏    │ 多标签 + 溢出下拉 + 多选 + 右键菜单            │
│侧├──────────┼──────────────────────────────────────────────┤
│工│ 侧边栏    │  编辑区（写作模式）                            │
│具│ ├ 文件列表│  或 源码模式 / 分屏模式（源码|预览）            │
│栏│ └ 大纲    │                                              │
├──┴──────────┴──────────────────────────────────────────────┤
│ 状态栏（打开路径 / 操作反馈 / toast）                          │
└────────────────────────────────────────────────────────────┘
```

五个 UI 层各自承载的入口：
1. **菜单栏**：低频全量入口（文件级操作、导出、视图切换、设置）。
2. **左侧竖向工具栏**（42px）：文件级高频操作 + 模式切换，共 8 钮 1 开关。
3. **标签栏**：文档生命周期操作（右键菜单 13 项，对标 Notepad++）。
4. **侧边栏**：文件列表 / 大纲 两个页签。
5. **编辑区浮层**（内核 editor.html）：斜杠菜单、块菜单、悬浮格式栏、表格工具栏、代码块顶栏、图片/图表块菜单。

## 第四部分 重设计参考要点

1. **入口冗余分布**（重设计时的合并/保留依据）：
   - 三通道重复：插入类功能（斜杠菜单 / Ctrl+Shift 快捷键 / 命令面板）；表格行列表格操作（tblbar 与块右键共用 buildTblbar）。
   - 双入口：模式切换（工具栏循环钮 + 视图菜单单选）；侧栏开关（« 钮 + Ctrl+Shift+L + 视图菜单）；保存（工具栏 + Ctrl+S + 菜单）。
   - 单入口：导出四通道仅菜单；历史版本仅菜单+面板；归档仅菜单。
2. **刻意设计勿破坏**：格式命令不设菜单（v3.31 决策）；Ctrl+Shift+T 归「插入表格」而非浏览器「重开标签」（v3.38 决策）；工具栏隐藏后边缘 » 常驻恢复（TB-1 防死局）；图表主题入口在系统设置不在视图菜单（MMD-11）。
3. **已知待优化项**：见《未实现BUG与优化清单-v3.30.11.md》第二十八章（文件列表 FL-1~6）、FMTB-7/8/9 等。
4. **架构约束**：存储恒为纯 Markdown（能原生就原生）；内核单文件 editor.html（CRLF，补丁脚本修改）；版本号唯一源 `config.APP_VERSION`。
