# 本书链接（BOOKLINK）设计说明书 · v3.45

> 目标：在书籍（mdBook）模式下，支持**快速对选定文本格式化**并**重新指定其指向本书内某个章节或锚点**的链接；操作便捷（一键 / 批量）；并明确定义链接的匹配规则、锚点命名规范与数据结构。

---

## 1. 总体方案

全书链接基于既有 `[[双链]]` 语法扩展，复用其解析 / 渲染 / 点击桥接通道，向下兼容笔记双链：

| 阶段 | 内容 | 状态 |
|------|------|------|
| A 锚点基础设施 | `slugify` 锚点派生 + `[[Target#anchor\|alias]]` 语法（编辑器 + 导出同源） | ✅ |
| B 选择器 UI | 浮动栏「本书链接」按钮 + 章/锚两级选择器（复用 `openSub`） | ✅ |
| C 跳转与锚点 | 点击链接跳章 + 滚动到锚点（`scrollToAnchor`） | ✅ |
| D 批量/诊断 | 侧栏「链接」页：全书链接清单 + 状态 + 批量修复 | ✅ |
| E 导出 | 导出 HTML 站点时 `[[ ]]` → 跨页 `<a href="page.html#slug">`，标题写 `id` | ✅ |

---

## 2. 数据结构 / 输出格式

### 2.1 源文件（Markdown）中的链接写法

```
[[章节标题]]                # 指向整章（章首）
[[章节标题#锚点]]           # 指向该章内某标题
[[章节标题#锚点|显示文本]]   # 带别名（显示文本与链接目标分离）
[[章节标题|显示文本]]        # 不带锚点、带别名
```

- 解析顺序：先按 `|` 拆分为「目标部分」与「别名」；目标部分再按首个 `#` 拆分为「章节标题」与「锚点」。
- 别名缺省时显示文本回落为章节标题；导出 HTML 时 `<a>` 文本 = 别名或章节标题。
- 兼容既有 `[[双链]]`（无 `#`、无别名）。

### 2.2 编辑器运行时注入（选择器数据源）

Python `refresh_book_links()` 经 `window.__bookLinks` 注入：

```json
[
  { "title": "第一章", "path": "…/ch1.md",
    "headings": [ { "level": 1, "text": "引言", "slug": "引言", "line": 1 },
                  { "level": 2, "text": "小节", "slug": "小节", "line": 5 } ] },
  …
]
```

### 2.3 侧栏诊断记录（`scan_book_links` 产出）

```json
[
  { "src_path": "…/ch1.md", "line": 12, "target": "第二章",
    "anchor": "小节", "alias": "", "status": "ok" },
  { "src_path": "…/ch2.md", "line": 3,  "target": "第三章",
    "anchor": "无效", "alias": "", "status": "anchor_missing" }
]
```

`status` ∈ `ok` / `anchor_missing`（章节存在但锚点不在该章） / `chapter_missing`（章节标题解析不到）。

### 2.4 导出 HTML（多页站点）

```html
<!-- 标题锚点（h1–h4） -->
<h2 id="小节">小节</h2>
<!-- 跨页链接 -->
<a href="02-ch2.html#小节">第二章小节</a>
```

## 3. 锚点命名规范（slugify）

单一事实来源：`src/mdutil.py::slugify` 与 `src/editor.html::slugify` 逐字符等价。

算法：
1. `trim`，内部连续空白折叠为单个空格；
2. 小写化（仅用于匹配，展示保留原文）；
3. 仅保留 Unicode 字母 / 数字 / 空格（CJK 原样保留），其余标点丢弃；
4. 空格 → `-`，去首尾与连续 `-`。

去重（章内）：同名标题靠 `-2` / `-3` 区分（`mdutil.heading_anchors`，仅对 **h1–h4** 计算，与选择器锚点清单、导出标题 `id` 完全一致）。

示例：`"## 引言"` → `"引言"`；`"## My Heading!"` → `"my-heading"`；`"## 小节"` + `"## 小节"` → `"小节"` / `"小节-2"`。

回退：空 slug（如纯标点标题）由调用方回落 `"section"`。

## 4. 链接匹配规则

### 4.1 章节解析（target → 章节文件）

书籍模式下，`on_wikilink` / `scan_book_links` 按章节标题在本书 `SUMMARY.md` 章节树中解析：

1. 精确匹配章节标题（`ch.title`）；
2. 大小写不敏感回退匹配；
3. 文件名（去扩展名）回退匹配（仅诊断 / 导出）。

解析不到 → `chapter_missing`（点击提示「书籍中未找到章节」，不新建文件以免污染书籍）。

### 4.2 锚点解析（anchor → 标题 id）

命中章节后，校验 `anchor` 是否属于该章 **h1–h4** 标题 slug 集合（`mdutil.extract_headings(..., max_level=4)`）：

- 命中 → `ok`，点击后 `scrollToAnchor(slug)` 平滑滚动并短暂高亮；
- 不在集合 → `anchor_missing`，诊断标黄，批量修复时剔除该失效锚点。

### 4.3 点击跳转（Phase C）

`mdeditor://wikilink?target=章节标题#锚点` → `acceptNavigationRequest` → `on_wikilink`：拆分 `target#anchor`，书籍模式打开该章（`open_book_link`）并在加载后 `setTimeout 400ms` 调 `scrollToAnchor(anchor)`；非书籍（笔记）模式沿用原双链行为（打开笔记 + 滚动锚点）。

### 4.4 导出映射（Phase E）

`bookhtml.build_site` 构造 `{章节标题: NN-章节名.html}` 映射，传给 `_blocks_to_xhtml(link_map=…)`；`[[Target#anchor\|alias]]` → `<a href="page.html#slug">`。无法解析（非书籍 / 目标缺失）时回落纯文本，避免导出死链。导出与编辑器共用同一 `slugify`，故锚点 `id` 与选择器 / 诊断完全一致。

---

## 5. 一键 / 批量操作

- **一键（Phase B）**：选中文本 → 浮动栏「📚 本书链接」→ 先选章节、再选锚点（可空，选「（章首）」即指向整章）→ 写入 `[[目标#锚点\|选中文本]]`。
- **批量 / 诊断（Phase D）**：侧栏新增「链接」页，列出全书所有 `[[本书链接]]` 并标注状态（✓ 正常 / ⚠ 锚点缺失 / ✗ 章节缺失）；双击跳转来源位置；「⟳ 刷新」重新扫描；「🛠 批量修复」带确认弹窗，自动剔除失效锚点、按标题（精确 / 大小写 / 包含）重映射失效章节，改写源文件后重新扫描。

---

## 6. 与既有双链的关系

本书链接是 `[[双链]]` 在书籍上下文下的定向扩展：语法、解析内核（`parseInline` / `exporters.parse_inline`）、渲染、点击桥接全部复用；区别仅在于书籍模式按章节标题解析而非按笔记目录索引，且支持 `#anchor`。非书籍模式下行为完全不变。
