# mdEditor 跨平台打包与分发（v3.47，P0 跨平台）

> 来源：SoloMD 竞品调研报告 §6.3 行动清单 **P0 项** —— 把 mdEditor 从「仅 Windows 可用」推进到 **macOS + Linux 完整打包分发**。
> 内核 PySide6 + QWebEngine 本身跨平台，本轮工作集中在**消除代码层的 Windows 专属耦合**与**补齐三平台构建/分发链路**。

## 二、构建体系（新增）

| 文件 | 作用 |
| --- | --- |
| `build.py` | **统一构建驱动**（三平台共用）。平台探测、按平台选 `--add-data` 分隔符（`;` / `:`）、**动态定位 PySide6 简体中文翻译**（不再硬编码 venv 路径）、显式 `hidden-import docx/pypdf/fpdf/openutil/secretstore/trash`、跨平台清场（Windows 用 `robocopy /MIR` 镜像空目录规避 safe-delete 批量守卫；POSIX 用 `shutil.rmtree`）。产出 onedir。 |
| `build_mac.sh` | macOS 封装：建 venv→装依赖→`build.py` 出 `.app`→codesign（可配 `MACOS_CERT_ID` 真证书，否则 ad-hoc）→`hdiutil` 打 `.dmg`→（可选）`xcrun notarytool` 公证 + staple。 |
| `build_linux.sh` | Linux 封装：`--deb` 开关。建 venv→装依赖→`build.py`→组装 AppDir 并下载 `appimagetool` 生成 **AppImage**；`--deb` 时再产出 **.deb**（含 desktop / icon / 包装脚本）。 |
| `requirements.txt` | 运行时：`PySide6 / pypdf / python-docx / fpdf2`；构建：`PyInstaller`。 |

### 用法

```bash
# 仅 PyInstaller 构建（当前系统）
python build.py                 # 用当前解释器（需已装 pyinstaller + 依赖）
python build.py --dry-run       # 仅打印命令，不构建

# macOS（在 Mac 上执行）
./build_mac.sh                                              # 构建 + ad-hoc 签名 + dmg
MACOS_CERT_ID="Developer ID Application: ..." ./build_mac.sh # 用真证书签名
NOTARIZE=1 APPLE_ID=you@icloud.com APPLE_TEAM_ID=XXXX APPLE_APP_PASSWORD=xxxx ./build_mac.sh

# Linux（在 Linux 上执行）
./build_linux.sh             # 构建 + AppImage
./build_linux.sh --deb       # 构建 + AppImage + .deb
```

## 三、各平台打包步骤

### 3.1 Windows（已验证）
- 既有：`build_exe.ps1`（Inno Setup 安装包 `installer/mdEditor-setup-<ver>.exe`）。
- 新版：`python build.py` 直接出 `dist/mdEditor/`（onedir），`build.py` 已内置 robocopy 清场，规避构建机 safe-delete 守卫。
- 安装包：沿用 `mdEditor.iss`（Inno Setup），已含中文语言包。

### 3.2 macOS（需在 Mac 上执行）
前置：
```bash
brew install python@3.13
xcode-select --install          # 提供 codesign / hdiutil / xcrun
```
执行 `./build_mac.sh`。要点：
- **QtWebEngine** 要求 `.app` 被正确签名；macOS 11+ 分发必须公证（Gatekeeper），否则其它机器会拦截。
- **图标**：把 `src/mdeditor.ico` 转成 `src/mdeditor.icns`（如用 `iconutil`）可获得完美 Finder 图标；缺省退回 `.ico`，运行不受影响。
- **公证**需 Apple Developer 账号 + app-specific 密码；`build_mac.sh` 中 `xcrun notarytool` 已留占位，首次用前先 `xcrun notarytool store-credentials "mdEditor" ...` 把凭据存入钥匙串。

### 3.3 Linux（需在 Linux 上执行）
系统依赖（Debian/Ubuntu 例）：
```bash
sudo apt-get install -y python3-venv python3-pip build-essential \
    libgl1 libglib2.0-0 libxkbcommon0 libdbus-1-3 libfontconfig1 fuse \
    libnss3 libxcomposite1 libxrandr2 libatk1.0-0 libatk-bridge2.0-0 \
    libcups2 libxdamage1 libxshmfence1
```
执行 `./build_linux.sh`（或 `--deb`）。要点：
- QtWebEngine 还需若干 `.so`（上表已列），若启动报缺库按提示 `apt-get install` 即可。
- AppImage 运行需 FUSE（或 `./xxx.AppImage --appimage-extract` 解包运行）。
- `.deb` 依赖已在 `DEBIAN/control` 声明（libgl1 等），安装后直接 `mdEditor` 启动。
