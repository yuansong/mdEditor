# 历史版本对比改进方案：双栏切换 + 词级高亮（v3.38）

> 2026-10-01 · 设计咨询产出，**未改 src**。被测对象：src/dialogs.py（DiffDialog L1459、HistoryDialog L1550）。
> 用户决策：单栏默认 + 双栏切换 + 词级高亮，**一次做齐**。

## 1. 背景与现状

当前版本对比为**单栏合并式（unified）**：`DiffDialog.show_diff`（dialogs.py:1494）用 `difflib.SequenceMatcher` 逐行比对，新增行绿底 / 删除行红底 / 上下文行灰字，静态 HTML 一次性灌入单个 `QTextBrowser`，超 `MAX_ROWS=4000` 行截断。入口两个：「与上一版本对比」（_diff_prev，L1703）、「与当前文档对比」（_diff_current，L1692）。

痛点：①整行着色——中文段落一行一段，改 3 个字则整段红 + 整段绿，看不出变化字词；②旧/新对应关系靠上下文推断，长文档定位费力。

## 2. 竞品默认值（决策依据）

| 产品 | 默认形态 | 切换能力 |
|---|---|---|
| GitHub | unified（合并式） | split 可切换 |
| VS Code | split（双栏，`diffEditor.renderSideBySide`） | inline 可切换 |
| Word「比较文档」 | 双栏 + 合并修订视图 | — |

结论：两种形态均有一线产品背书，**行业通行解是切换项而非二选一**；我方取「单栏默认 + 切换」，与 GitHub 心智一致（同为轻量场景为主）。

## 3. 交互设计

1. **视图切换**：DiffDialog 标题行下增工具行，放单选式切换「单栏 | 双栏」（QComboBox 或两个可勾选 QAction 均可），**默认单栏**；选择写入 QSettings（键名建议 `diff/layout`，沿用现有设置读写方式），跨会话记忆。
2. **列头**：双栏模式下显示左右列标题，直接复用现有 `old_label` / `new_label` 参数（如「快照 2026-10-01 09:12:00」/「当前文档」）；单栏模式保持现状统计行不变。
3. **双栏布局**：`self.view` 替换为 QSplitter(水平) 内两个 QTextBrowser（左右各一），中间分隔条可拖；窗口默认宽从 860 提到 **1100**（双栏下 860 每栏 ~400px 过窄；仅当用户切到双栏且窗口未手动改过尺寸时放宽一次，避免打扰单栏用户）。

## 4. 词级高亮设计（两模式共用）

- **配对时机**：仅对 `get_opcodes()` 产出的 `replace` 块内 del/add 行**按顺序 1:1 配对**；配对后仍有余量的行（一侧多出）退化为整行着色。纯 `delete` / `insert` 块不做词级（无对应物）。
- **算法**：对每对行跑 `difflib.SequenceMatcher(None, old_line, new_line, autojunk=False)` 字符级比对（中文无空格分词问题，按字符天然可切），`get_opcodes()` 中非 equal 段用 `<span>` 包裹高亮。
- **性能护栏**：行字符数 > 300 的对跳过词级、退整行着色；行数上限沿用 MAX_ROWS。
- **配色**（行底色沿用现有 c_add/c_del 两档分支；词级取更深一档）：
  - 浅色主题：行底 `#e2f6e9` / `#fde8e8`，词级 `#9FE1CB` / `#F5C4B3`；
  - 深色主题（dark/night/panda）：行底 `#1e3b2a` / `#3f2222`，词级 `#2a5c42` / `#5c2f2f`。
- **HTML 层**：仅改 show_diff 的行渲染函数，输出结构不变（`<div>` 行 + 可选内嵌 `<span>`），QTextBrowser 零依赖路线保持。

## 5. 双栏渲染设计

- **行流构造**：抽公共函数 `build_rows(old_lines, new_lines)` 返回配对序列 `[(kind_l, text_l, kind_r, text_r)]`：
  - `equal` → (ctx, 原文, ctx, 原文)
  - `replace` → del 行与 add 行逐行配对，余侧补 spacer
  - `delete` → (del, 原文, spacer, "")；`insert` → (spacer, "", add, 原文)
  - 单栏模式从同一序列投影（忽略右列、spacer 行跳过），保证两模式内容一致。
- **spacer 样式**：淡色上下边线的空行（与对面改动行等高），标示「此侧无对应内容」。
- **同步滚动**：两视图 `verticalScrollBar().valueChanged` 互连，handler 内 `blockSignals(True)` 防递归。
- **截断**：MAX_ROWS 在双栏下按**行对**截断，左右行数恒等。
- **对齐近似声明（重要）**：QTextBrowser 自动换行后同一逻辑行占多个视觉行，长段落两侧可能错位 1~2 视觉行。本期接受近似（词级高亮已承担主要定位职责）；像素级对齐需换自绘/QWebEngine，不列入本期。

## 6. 实施拆解与工作量

| 步骤 | 内容 | 预估 |
|---|---|---|
| T1 | 词级高亮：replace 块配对 + 字符级 diff + span 生成 | 0.5 天 |
| T2 | 双栏布局：QSplitter + 双 QTextBrowser + 列头 + build_rows 重构 | 0.5 天 |
| T3 | 切换控件 + QSettings 记忆（diff/layout） | 0.5 小时 |
| T4 | 双栏同步滚动（防递归互连） | 0.5 小时 |
| T5 | 探针验证（见 §7）+ 双主题人工过目 | 0.5 天 |

合计约 **2 天**。改动面收敛在 DiffDialog 一个类内，HistoryDialog / mainwindow 零改动。

## 7. 验收标准（可探针化）

1. 默认（首次打开）仍为单栏，输出与现状语义一致（回归护栏）；
2. 双栏模式左右行数（含 spacer）相等；切换布局不重算 diff（缓存 rows）；
3. 词级 span 仅出现在 replace 配对行内，且 >300 字符行不出现；
4. 切换选择跨会话记忆；
5. dark/night/panda 三深色主题下词级色可读（人工过目）。

探针建议沿用 `_m10x` 系列（如 `_m108_diff.py`）：构造临时文档 + 快照 → 直调 `DiffDialog.show_diff` → 检查生成 HTML（词级 span 存在性 / 双栏 spacer 对数 / 单栏回归），不依赖人工点击。

## 8. 风险与边界

- **性能**：词级 diff 仅作用于 replace 配对且 ≤300 字符，最坏情形（全文逐行改写）退化为现状整行着色，不劣化；
- **超长文档**：MAX_ROWS 截断逻辑两模式一致，双栏下按行对截断；
- **主题**：三深色主题走现有 `dark = theme in ("dark", "night", "panda")` 分支，词级色同步两档；
- **窗口尺寸**：860→1100 仅在「切双栏且用户未手动调过尺寸」时执行一次，避免改变单栏用户习惯。

## 9. 任意两版本对比（DIFF-2，2026-10-01 追加需求）

**需求**：目前只有「与上一版本对比」「与当前文档对比」两条固定路径，无法任选两个历史快照互比（例如找回 3 天前某版与上周某版的差异）。

**交互设计**（零新增控件层级，复用现有列表）：

1. `listw.setSelectionMode(QAbstractItemView.ExtendedSelection)`（dialogs.py:1578 处加一行）——**单击仍是单选预览**，`currentRowChanged → _on_pick` 链路完全不变；
2. 新按钮「**对比所选两项**」，插在「与上一版本对比」左侧；仅当 `selectedItems()` 恰为 **2** 时启用（Ctrl+点选 / Shift 区间选满两项即亮），其余状态禁用；
3. 点击后取两项快照文本，按 mtime **旧→新**作为 old/new 调 `show_diff`（复用现有 DiffDialog，标题「版本对比 · 文件名」，labels 用两个快照时间）——自动获得 §4 词级高亮与 §5 双栏切换全部能力；
4. 空态 / 单快照文档：按钮与现状按钮一起禁用（沿用 show_for 的空态分支）；
5. 快照列表在对比期间被外部清理（保留份数滚动淘汰）：`_snap_text` 返回 None 时 toast/忽略即可，沿用现有静默返回模式。

**与现有按钮的关系**：「与上一版本对比」「与当前文档对比」保留为快捷路径，不合并语义（三个按钮并列，禁用态各自独立）。

**工作量**：约 **0.5 天**（选择模式 + 按钮启用逻辑 + 取值排序接线；DiffDialog 零改动）。验证可并入 §7 探针：`listw.selectedItems()` 为 2 时断言按钮 enabled、对比结果行数与手算 difflib 一致。
