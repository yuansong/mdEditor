# 标签页右键菜单方案：批量关闭 + 复制路径（Notepad++ 对标）v3.38

- **日期**：2026-10-01
- **需求来源**：用户提出，对标 Notepad++ 标签右键菜单
- **现状取证**：`_tabbar` 为 QTabBar（mainwindow.py:319-327，movable + closable），**无右键菜单**；312/401 的 CustomContextMenu 挂在编辑视图上与 tabbar 无关。`_docs=[{path,content}]` + `_cur` 双轨管理；`_close_tab`（1853）单标签关闭已含未命名保存确认链；`show_in_explorer`（1123）已存在但未入标签菜单
- **实施方**：并行会话（本文档仅为设计与登记）

---

## 一、需求项设计

### TAB-1 批量关闭组（4 项）

菜单挂载：`_tabbar.setContextMenuPolicy(CustomContextMenu)` + `customContextMenuRequested` → `tabBar().tabAt(pos)` 定位目标标签，无命中（空白区）时菜单不出或仅出「关闭所有」。

| 菜单项 | 行为 |
|---|---|
| 关闭 | 复用 `_close_tab(idx)`（现有确认链原样生效） |
| 关闭其他所有 | 保留当前标签 + 目标标签语义 = N++「关闭除当前外全部」：关闭除 `idx` 外全部 |
| 关闭左侧所有 / 关闭右侧所有 | 批量关闭 `idx` 左/右侧全部；若无则置灰 |
| 关闭所有未修改 | 关闭全部 `dirty == False` 标签（见前置改造） |

**批量关闭实现要点**：

1. **从右往左逐个移除**（倒序循环 `removeTab`），避免索引漂移；`_cur` 修正逻辑复用 `_close_tab` 的分支语义（1844-1851 的 `_on_tab_moved` 同款修正表）；
2. **确认策略**：逐个弹窗会被打断节奏且 N++ 行为是逐个确认。推荐**两段式**：先扫描出含未保存内容的标签集合 → 0 个直接批量关；≥1 个先弹一次汇总确认（「有 N 个未保存文档，全部保存 / 放弃更改 / 取消」）→ 再倒序执行；「未命名非空」沿用现有 `_close_tab` 判定口径；
3. **执行期间加 `_switching` 同位锁**，防止批量过程中异步 `getMarkdown` 回调与用户点击交错（`_on_switch_capture` 已有该锁的先例）；
4. 全部关闭后走 `_close_tab` 现有的「空栈自动补空白页」分支（1879-1883）。

**前置改造：per-doc dirty 追踪**（「关闭所有未修改」的可靠性前提）：

- 现状 `_dirty` 只覆盖**当前**文档，且 `_on_switch_capture`（1829）切换时直接 `self._dirty = False`——切走再切回，修改标记丢失；
- 方案：`_docs` 增 `doc["dirty"]`。①切换前把 `self._dirty` 存入 `doc["dirty"]`（`_on_tab_clicked` 缓存 content 处同步）；②编辑修改信号（现 `markDirty` → Qt 的 1065 `self._dirty = True`）同步写 `self._docs[self._cur]["dirty"] = True`；③保存成功处清零。`_refresh_tab_texts`（1778）改读 `doc["dirty"]`，**顺带修复「非当前标签不显示 •」的既有缺陷**；
- 兜底：`doc.get("dirty")` 缺失时用 `content != 磁盘内容` 比对（未命名非空视为已修改，与 `_close_tab` 1862 口径一致）。

### TAB-2 复制组（3 项）

| 菜单项 | 内容 | 置灰条件 |
|---|---|---|
| 复制文件名 | `os.path.basename(path)` | `path is None`（未命名置灰） |
| 复制文件路径 | 完整路径（含文件名） | 同上 |
| 复制当前路径 | `os.path.dirname(path)` 纯目录 | 同上 |

实现：`QApplication.clipboard().setText(...)`；成功后 `_toast` 提示「已复制：…」（状态栏右侧现有 toast 通道，3 秒自动还原）；路径分隔符用系统原生（Windows `\`），不做正斜杠转换。

### 菜单结构建议（含已有功能收编）

```
关闭                Ctrl+W（已有快捷键则标注）
关闭其他所有
关闭左侧所有        置灰：idx==0
关闭右侧所有        置灰：idx==末位
关闭所有未修改      置灰：全部未修改（可改为禁用态提示）
──────────
打开所在文件夹      （收编现有 show_in_explorer，定位到文件）
复制文件名
复制文件路径
复制当前路径
```

分隔线以下即 N++ 的「文件操作组」；后续候选（见第三章）按组追加。

## 四、验收标准（可探针化）

1. 右键第 i 个标签 → 菜单项与置灰态正确（首/尾/全未修改/未命名各态）；
2. 「关闭其他」：3 文档含 1 未命名非空，从中间标签关闭其他 → 汇总确认弹一次 → 结果只剩当前 + 未命名按口径处理；
3. 「关闭左侧/右侧」：倒序移除后 `_docs` 与 `_tabbar` 索引一致（切一遍每个标签内容无损）；
4. 「关闭所有未修改」：2 修改 + 1 未修改 → 只关未修改；dirty 标记切走切回不丢；
5. 复制三项：剪贴板内容与 `os.path` 结果一致，未命名置灰；
6. 批量关闭过程中快速点击其他标签 → 无交错错乱（`_switching` 锁生效）。
