## 3. 模糊测试：设计、执行与归因

- **设计**：固定种子 ×3（20261001/42/777）× 60 步。操作池 7 动作随机；选区随机（含折叠）；每 5 步 undo/redo 交替；每 8 步轮换注入非常规内容（空串 / 4000 字超长段 / HTML 标签与引号等特殊字符 / 混合中英 / 已含标记文本）；每步断言：渲染态无字面标记泄漏 + raw 无 `~~~~/******/===== /```` 脏游程 + 页面存活。
- **执行**：180 步，无崩溃、无页面死亡、超长与空内容均未引发独立故障。
- **归因**：62 处断言失败**全部**归因于同一根因 FMTB-5（泄漏一旦产生即持续残留，被后续步骤重复计数）。最小复现见 §4。种子 42 的泄漏从 s7（内容注入步）起持续，与「基础内容含标记 + 随机部分选」模型一致。

## 4. 发现的问题

### FMTB-5（真实缺陷，P3）：选区横跨已有行内格式边界时套格式 → 渲染层泄漏字面标记

- **复现步骤**：①输入 `普通中文段落包含标点和数字123。`；②选中「文」点斜体 → `普通中*文*段落…`；③选中「通中文」（起点在斜体内、终点在外）再点斜体。
- **实际**：raw 变 `普*通中*文**段落…`，渲染为 `普<em>通中</em>文**段落…` ——字面 `**` 以正文显示（DOM 实证）。链接同型：部分选链接文字加粗得 `**[文字**链接](url)`，链接文字被劈开；对该状态再点 toggle 恶化为 `****[文**字**链接](url)`（`****` 脏游程），无法通过再次操作恢复。
- **影响范围**：全部 7 个行内格式动作 × 标题/列表/引用/段落/表格单元格等所有宿主块；破坏「始终保持渲染状态」验收标准；脏 raw 落盘后导出亦损坏。
- **根因**：跨行守卫（editor.html:8556）只拦截含 `\n` 的映射区间；选区**区间内部横穿标记字符**时无任何守卫。FMT-5b（外推判定）与 FMT-7（防交错）只覆盖「选区边界紧邻成对外壳游程」情形，覆盖不了「中间横穿」。
- **修复建议**：保守修——跨行守卫处扩展：映射区间内部扫到 `*_~=\`` 任一标记字符即拒绝应用并 toast（杜绝脏 raw，约 1 天）；后续可评估「先清后套」语义。

### FMTB-6（竞态观察项，P4）：350ms 快照防抖窗口内双操作后立即撤销失效/跳档

- **复现**：350ms 内连续应用两次格式操作后立刻 Ctrl+Z——撤销无反应（快照未入栈）或一步跳两档。`_m109f` 矩阵：间隔 500ms 的 3/4 序列复现，1s 全过。探针环境定时器节流放大了窗口；真实场景=快速连点两个格式按钮后马上撤销，低概率但可感知。
- **根因**：`scheduleSnapshot`（4219）350ms 防抖期间撤销，`undoStack` 未含最新档。**修复**（约 2 小时）：格式操作路径收尾直接同步 `snapshotNow()`。
