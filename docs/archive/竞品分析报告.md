# mdEditor 竞品分析报告（2026-09）

> 分析对象：Typora、Obsidian、有道云笔记、Notion、Joplin/思源（简述）、试卷宝/拍试卷（教育场景参照）。
> 目的：明确 mdEditor 的定位与差异化，找出值得借鉴的能力，并为「错题/教育」场景延伸提供依据。

---

## 一、mdEditor 当前定位

**本地优先的中文 Markdown 块级所见即所得编辑器**：
- 真正的块级 WYSIWYG（斜杠菜单插入、表格合并拆分、图表/公式就地源码编辑），比 Typora 的行内渲染更进一步
- 单文件 + 文件夹浏览，无账号、无云依赖、免费，数据完全本地
- 中文场景优化：中文翻译、字数统计（中英文分计）、图注、emoji、脚注、定义列表
- 导出：PDF（含书签）/ Word / EPUB / HTML（docx/EPUB 依赖 pandoc）

## 二、竞品逐个对比

### 1. Typora（¥89 买断 / 订阅）
| 维度 | Typora | mdEditor |
|------|--------|----------|
| 编辑模型 | 行内实时渲染（源码即视图） | 块级渲染态编辑 + 源码态切换 |
| 表格 | 简单表格，不支持合并单元格 | **合并/拆分/整行整列/网格建表（更强）** |
| 图表 | mermaid 支持（代码态为主） | 就地源码框 + 实时重渲染 + 尺寸/图注属性 |
| 导出 | PDF/Word/EPUB/HTML 内置 | 同等覆盖（pandoc 依赖） |
| 价格 | 收费 | **免费** |

**结论**：mdEditor 在表格/图表/图片管理上已超过 Typora；差距在**打磨度与性能**（超长文档流畅度、快捷键手感、主题生态）。

### 2. Obsidian（免费，同步收费）
- 强项：双链、图谱、插件生态、本地 .md 文件
- mdEditor 没有且短期不必做的：双链/图谱（定位不同）
- **可借鉴**：①插件化的命令面板（mdEditor 已有雏形）②「大纲即导航」体验 ③模板插入（template 插件思路 → mdEditor 可做「常用片段」库）

### 3. 有道云笔记（免费+会员）
- 强项：多端同步、云端存储、Markdown+富文本混合
- **可借鉴**：①「收集—整理—复用」闭环（mdEditor 可加「快速笔记」入口）②目录树管理（对应 UX 报告 #5 树形目录）
- 差异点：有道云重云重协作；mdEditor 重本地重写作，不正面竞争

### 4. Notion（免费+订阅）
- 强项：块编辑、数据库、协作
- mdEditor 的块级模型与 Notion 神似但**服务于 Markdown 保真**（Notion 导出 .md 会丢失信息，mdEditor 始终真 .md）
- **可借鉴**：块拖拽排序（对应 UX 报告 #7 大纲拖拽）、块颜色/标注

### 5. 试卷宝 / 拍试卷（教育场景，与用户错题小程序直接相关）
试卷宝核心链路：拍照 → 自动裁边 → **清除手写笔迹还原空白试卷** → 分科目整理 → 生成错题集 PDF → AI 出相似卷。
- 功能清单：试卷擦除、拍错题、图片转 Word、公式识别、科目/标签管理、错题集 PDF 导出、云端多设备、AI 智能出卷
- 商业模式：免费额度 + VIP（连续包月 19 元 / 年 168 元）

**对 mdEditor 的启示**（若向教育/错题场景延伸）：
1. mdEditor 的「图片 assets 管理 + 图注 + 导出 PDF/Word」天然适合做**桌面端错题集整理器**：拍照/截图 → 插入 → 图注写知识点 → 按标签文件夹管理 → 一键导出错题集 PDF
2. 可新增「错题模板」：题目图片 + 知识点标签 + 错因 + 重做日期（用定义列表/表格承载），配合导出即轻量错题本
3. 与用户的错题小程序形成**端协同**：小程序负责拍照采集/OCR（腾讯云 OCR），mdEditor 负责桌面端深度整理与导出打印 —— 这是试卷宝（纯移动端）没有的组合
4. 暂不建议做：笔迹擦除/试卷还原（算法重，且小程序侧已有规划）

### 6. Joplin / 思源笔记（简述）
- Joplin：开源免费、同步灵活，界面朴素 → mdEditor 的界面质感是优势
- 思源：块引用/反向链接强，部分收费 → 印证「块级编辑」方向的用户需求真实存在

## 三、差异化定位建议（一句话）

> **「免费、本地、真 Markdown 的中文块级编辑器——写作像 Notion 一样直观，文件像 Obsidian 一样自主。」**

近期可强化的差异化标签：
1. **表格能力标杆**（合并/拆分/网格，竞品中最强）—— 官网/README 应放对比表
2. **中文写作细节**（字数分计、中文翻译、图注、错题模板等教育场景）
3. **零依赖起步**（安装即用，pandoc 仅导出 Word/EPUB 时按需引导）

## 四、风险与机会

| 类型 | 内容 |
|------|------|
| 威胁 | Typora 降价/恢复买断；Obsidian 插件「Enhanced tables」补齐短板 |
| 机会 | ①Typora 收费留下的免费替代需求 ②中文用户对本地笔记工具的隐私偏好 ③教育错题场景桌面端空白 ④与错题小程序的端协同 |
| 须守住 | 真 .md 文件保真（不做私有格式）、启动速度（<1s）、免费 |
