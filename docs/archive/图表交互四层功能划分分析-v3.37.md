## 三、发现的问题

### MMD-14（P2）：单元格内图表零编辑入口 + 两处死文案【实锤】

- `/` 菜单可在单元格插入图表（7860-7864，cell-mmd 占位），渲染后**没有任何编辑路径**：
  - 双击 handler 只认 `#editor .mermaidblock`（7348），单元格内是 `div.cell-mmd`（经 `renderMermaidEl` 渲染，2749-2754），`closest('.mermaidblock')` 必不匹配——选择器级确定，非时序偶发；
  - objbar / blkmenu 均为块级交互，表格块整体路由到表格菜单，进不到格内图表。
- 连带**死文案**两处：空占位「图表代码为空，双击输入 mermaid 代码」（2752）与错误态「双击图表可继续编辑」（2794）在单元格内都是空头承诺（CSS 上专门为 `.cell-mmd .mmd-err/.mmd-tip/.mmd-src-show` 写了样式 184-192，说明该场景是预期支持的）。
- 用户唯一出路：删掉重插。修复参照同格公式的成熟先例：双击 `.cell-math` 弹层编辑（MATH-5，7340-7345 `openCellMathPop`）——图表做 `openCellMmdPop` 即可，文案随入口生效自动救活。

### MMD-15（P3）：删除块四重入口 + 图表上下文格式栏冗余

选中图表（objbar 在场）再拖选 svg 文本时，格式栏（🗑）与 objbar（删除）**同时在场**，同一动作同屏双钮；加上 blkmenu 与 DEL 键共四路。`fbDelOnly` 对图表的价值只是防御（防止 `**` 写进源码），但「删除整个块」按钮在行内格式栏上纯属顺带。建议：`buildFloatbar` 的 delOnly 形态对图表上下文（非源码框态）不出浮条——图表选中已有 objbar 承接，且误拖 svg 文本的概率高于真实格式化需求。代码块 / 公式块可先保留现状（它们没有 objbar）。

### MMD-16（P3）：objbar 图表分支是「半收敛态」，与图片分支不对称

v3.37（TBL-F1）刚以「低频集合型操作不该独立成浮层」为由删掉 objbar 表格分支，保留图表分支的理由是「高频源码编辑符合单钮条形态」（13039-13042 注释自述）——但实际是 **4 钮**：源码、删除与 blkmenu 重复（2/4），图注、重置尺寸是 objbar 独有。对照同体系的图片（v3.30.17 起选中只出蓝框、操作全在右键菜单）：图片的「图注 / 重置尺寸」在 special menu image 分支（9651-9652），图表的却在 objbar——**同一套 selectObj/cappop/resetObjSize 原语，两个兄弟对象操作位置不同**，用户无法形成稳定预期。

**建议方案（对齐图片）**：
1. blkmenu chart 分支补「图注」「重置尺寸」两项（放「编辑源码」后、「图表主题」前）——与 image 分支结构完全对称；
2. objbar 收缩为「源码」单钮（缩放框照旧），兑现注释里自己声明的「单钮条形态」；
3. 若追求更彻底，可连「源码」单钮一并移除（双击图表已是低门槛入口），但保留单钮的收益是鼠标单程可达，成本仅一个按钮，**倾向保留**。

### 可发现性评估（对照 TBL-F3）

图表是五类特殊块中**可发现性最好的**：单击即选中（蓝框 + objbar 点击即见 + 手柄脉冲），无需记忆快捷键；双击进编辑符合桌面直觉。主题入口藏右键二级 + 设置面板，属低频可接受。结论：图表块不需要 TBL-F3 式的补发现性动作，收敛方向与表格一致——**继续减少浮层，不是增加**。

## 四、功能划分方案（对照表格原则）

| 层 | 职责 | 图表块落地 |
|---|---|---|
| 格式栏 | 纯行内格式 | **完全退出图表上下文**（含 delOnly 删除，见 MMD-15） |
| objbar | 高频单动作 + 手势 | 「源码」单钮 + 缩放框（MMD-16 收缩） |
| blkmenu/右键 | 块级集合操作（编辑入口 / 图注 / 重置尺寸 / 主题 / 移动 / 复制 / 删除） | chart 分支补图注、重置尺寸，与 image 对称 |
| 右键 | 与 blkmenu 同体 | 维持（表格是唯一需要独立结构化右键的块型） |
| 单元格内 | 弹层编辑 | 补双击弹层（MMD-14，MATH-5 先例） |

**是否需要把悬浮菜单操作独立为悬浮命令？不需要。** 图表的高频动作（改源码）已有双击 + objbar 双通道即点即得；其余全是低频集合型，不符合「高频 + 单动作 + 即点即得」标准。与表格结论同向：**收敛浮层数量，把一致性（图表 vs 图片对称）和入口有效性（单元格图表）补齐**。
