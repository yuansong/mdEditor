## 0. 一句话结论

代码块的**编辑内核相当完整**（渲染态直编、语言搜索切换、Tab 批量缩进、四种键盘退出、风格/行号持久化、内容安全守卫均已落地），缺口集中在**三处能力缺失**（折叠、全屏、自动换行开关）与**两处体验瑕疵**（末尾块 Esc「假退出」、复制入口不可见）。

## 1. 模块能力全景

代码块是**单浮层 + 块级顶栏**结构，不与 objbar / blkmenu 发生关系（对比图表块的四层交互）：

| 交互面 | 载体 | 承载操作 | 触发方式 |
|---|---|---|---|
| **代码栏 codebar** | `.codeblock > .codebar`（2486） | 语言选择、风格/行号设置、（右键）复制全部 | 常驻显示，无需先进入编辑 |
| **代码区** | `pre.fence > code[contenteditable=plaintext-only]`（2520） | 全部编辑行为 | 单击 / 方向键导航进入 |
| **行内格式栏（降级形态）** | `#floatbar`（delOnly） | 仅「🗑 删除整个块」+「已选 N 字」 | 在代码区拖选文字（160ms 后） |
| **系统右键菜单** | 原生 | 复制 / 粘贴 / 拼写 | 代码区右键（5860 直接 return，不弹自定义菜单） |
| **块菜单 blkmenu** | — | **不参与**（`specialBlockKind` 9642 不含 fence） | — |

> **与引用块的结构差异**：引用靠「块本身可编辑 + 块菜单转段落」；代码块靠「块内独立编辑区 + 顶栏」，**没有块级选中态、没有 objbar、没有块菜单**——这决定了它的删除入口只有一条（见 2.7）。

| X-7 | **点击块外区域** | 点击非代码块区域 | 光标进入被点块；点击编辑区**空白**且末尾是代码块 → **追加空段**进入（不再回到代码区） | ✅ | E6（3142-3153） |

| X-10 | Tab / Shift+Tab | — | **不是退出**（缩进/反缩进） | ✅ | D1-D3 |

**推荐退出机制定义（规范）**

1. **主退出**：Esc / Ctrl+Enter —— 保存并跳下一块；**若已是末块，则在其后追加空段落并进入**（与 X-7「点击空白」同款，杜绝「跳无可跳」）。
2. **边界跳出**：↑/← 在首行起始、↓/→ 在末行末尾 —— 保存并跳相邻块（现状正确，保持）。
3. **指针离开**：点击块外 / 焦点移出 —— 保存 + 重新着色，**不改变块结构**。
4. **禁止路径**：Tab 不得移出焦点（现状已拦截为缩进，正确）；代码区内 Backspace/Delete 在边界**不得删块**（现状正确）。
5. **反馈一致性**：任何「已退出」提示必须与真实落点一致（X-9 违反）。

## 3. 注意事项与易错点

### 3.1 光标在代码块「内外」的行为差异

| 场景 | 块外（普通段落/标题） | 块内（代码区） |
|---|---|---|
| 单击 | 进入该块编辑 | 进入代码区，**不切源码态**（5763） |
| 拖选文字 | 格式栏 = 完整格式化按钮组 | 格式栏 = **仅删除**（`fbDelOnly` 7619） |
| Ctrl+B / I / U 等 | 生效 | **安全无效**：`_m102d` T3 实证触发加粗 QAction 后 raw 完全未变（`print('hi')` 未被插入 `**`） |
| Tab | 列表缩进 / 表格跳格 | **插入 2 空格**（不跳焦点，12172） |
| Enter | 拆块 | 换行（12168） |
| Backspace（行首） | 与上块合并 | **只删字符**（R6） |
| 右键 | 块菜单 / 插入菜单 | **系统菜单**（5860）——无「删除块」「复制代码」 |

**易错点 ①**：以为「选中代码 → Ctrl+B 能给代码加粗」。实际不会生效且**无提示**（安全但静默）。规范建议：保持静默（代码区不是富文本区），但应在帮助面板写明。

**易错点 ②**：以为「右键代码块有块菜单」。实际只有系统菜单——删除必须走格式栏。

### 3.2 换行与缩进

| 项 | 行为 | 易错点 |
|---|---|---|
| Enter | 插入裸换行，**不继承上一行缩进** | ⚠️ 手写 Python 时每行缩进都要自己敲（Notion/飞书同样不自动继承，属行业常态） |
| Tab | 插 **2 空格**（硬编码 12189），非语言感知、非 Tab 字符 | ⚠️ 粘贴外部 Tab 缩进代码后，混用空格/Tab 需自行统一 |
| Shift+Tab | 仅剥离行首 **1~2 个空格**（12204） | 对 4 空格缩进需按两次 |
| 跨行选区 Tab | 按行批量缩进/反缩进，完成后**选区复原** | ✅（CODE-6） |
| 尾部空行 | 保留 ≤2 | 多余空行被收敛（CODE-5 设计） |
| ` ``` ` 内容 | 拒绝写入 | ⚠️ 需在源码态改用四反引号围栏（toast 已指引） |

### 3.3 快捷键冲突

| 快捷键 | 在代码块内的行为 | 冲突风险 |
|---|---|---|
| `Esc` | 退出到下一块 | 与「关闭弹层」无冲突（弹层打开时优先关弹层，9354） |
| `Ctrl+Enter` | 退出到下一块 | ⚠️ 与「发布/提交」类直觉冲突（语雀为发布文档）——本产品无此冲突 |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进 | ✅ 已拦截，不会移出焦点 |
| `Ctrl+Shift+K` | 插入新代码块 | 代码区内触发会插入新块（合理） |
| `Ctrl+B/I/U` | 无效（T3 实证） | ✅ 安全 |
| `Ctrl+A` | 未专项验证 | ⚠️ 建议确认是「全选代码」还是「全选文档」（待人工验证项） |
| `Ctrl+C/V` | 系统复制粘贴 | ✅ |

### 3.4 内容与存储

- 存储形态：首行 ` ```lang st=xxx lnum=x `（info 属性持久化），中间原样代码，末尾 ` ``` `。
- 语言名统一**小写**写入（CODE-7），按钮显示保留用户输入原样。
- 代码块**不计入正文字数**（5950 注释；mainwindow 853 说明）。
- 数字/关键词高亮为自研轻量 tokenizer（2254），非完整语法树——极端语法可能着色不准（可接受）。
