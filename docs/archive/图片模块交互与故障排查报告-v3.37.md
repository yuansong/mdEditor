## 一、结论摘要

1. **主体功能完整且稳定**：插入 → 渲染 → 选中 → 尺寸 / 图注 / 对齐 → 复制 / 移动 / 删除 全链路实测通过，64 项断言中 **59 项 PASS**，无源码泄漏、无内容漂移。
2. **交互模型与其它特殊块不同**：图片是**「选中 + 右键菜单」单浮层模型**——点击只出蓝框 + 缩放框，`objbar` 明确不弹（13532），所有操作收在右键菜单（9815-9854）。这与图表（objbar 4 钮）是有意的差异化，但**造成了操作项不对称**（见 IMG-10）。
3. **存储三态能力领先竞品**：相对路径（assets 落盘）/ 内嵌 data URL / 网络 URL 三态可选 + 批量本地化，是云端竞品（Notion / 飞书 / 语雀）不具备的本地 Markdown 编辑器特性。
4. **新登记 4 个问题**：IMG-10 图片块缺「复制块」（图表有）、IMG-11 特殊块菜单边界不置灰、IMG-12 未保存文档时存储类菜单项静默消失、IMG-13 选中后键盘删除受焦点守卫拦截。**均为 P3**，无 P1/P2。
5. **竞品差距集中在「图片编辑」而非「图片排版」**：我方在精确尺寸（px/%）上**强于**飞书（官方明确不能精确调整）与 Notion（仅拖拽）；差距是**裁剪**（飞书 / 语雀有）、**替换图片**（Notion / 语雀有）、**多图并排**（飞书 / Notion 有）——按 Markdown 编辑器定位建议裁剪类不做。

## 三、故障 / 异常清单（用户点名的 5 类）

### 3.1 粘贴图片 —— 机制正确，有 700ms 延迟窗口

- **链路**：JS 拦截 paste（6866）→ `FileReader` 转 data URL → assets 模式写入 `window.__imgPending` → **下一次 `collect()` 轮询（700ms）**带出 → Python 落盘 → 回调 `insertImageMarkdown` 插入相对路径（6882-6884）。
- **风险点**：① 粘贴后最长约 700ms 才出现图片（快速连续粘贴多张时，`__imgPending` **只保留最后一次**——6894-6895「只上报一次」，若 700ms 内连贴两张，前一张的 data URL 会被覆盖丢失）；② 落盘失败回退内嵌并提示（mainwindow 1267）。
- **是否需优化**：连贴丢失属低概率但后果明显（图片消失），建议 P3：改为队列 `__imgPendingList`。

### 3.2 拖入插入 —— 已修，边界清晰

- 多图全部插入（IMG-1，3128-3142）；拖入 `.md` 只打开第一个；非图片非 md 忽略。
- QWebEngine 子控件吞 drop 的问题已用事件过滤器解决（3144-3170）。
- **未见异常**，无新增优化项。

### 3.3 编辑区与源码同步 —— 无漂移 ✅

- 图片块的唯一真相是 raw（`![…]` 或 `<figure>` HTML）；渲染 → 编辑 → 切源码 → 切回，实测 raw 逐字一致（_m104c 末项 PASS）。
- `figFromRaw` / `writeFigure`（12874-12928）保证 figure ↔ spec 双向解析一致。

### 3.4 导出时的图片处理 —— 有自检，策略明确

- 网络图片导出前自检提示「查看时需联网加载；本地图片与公式 / 图表已内嵌，离线可用」（mainwindow 2106-2113）。
- 本地图片与公式 / 图表**内嵌**进导出物（离线可用）；网络图保留 URL。
- 编辑器内部记号 `data-md`（回写用原始相对路径）**不进导出物**（6947 注释，v3.36）。
- **未见异常**。可选优化：导出前提供「把网络图一并转内嵌」开关（P3）。

### 3.5 大图 / 多图性能 —— 有体积提示，无压缩

- 内嵌模式插入时按体积给提示（mainwindow 1284：约 N MB 提示）；文档体积随图片线性增长。
- **无压缩 / 无缩略图**：内嵌多张大图会让文档与内存占用显著上升（竞品均为云端托管，无此问题）。
- **是否需优化**：P3，建议插入大图（> 2MB）时建议改用 assets 相对路径模式（当前仅提示体积，未给建议）。

## 七、需人工验证项（探针无法覆盖）

1. **真实文件粘贴 / 拖入落盘**：探针用 data URL 构造；真实 PNG 粘贴后 assets 目录是否生成 `NNNNN_名称.png`、状态栏提示是否正确——需手工验证一次。
2. **大图（>5MB）内嵌**的插入耗时与内存表现、体积提示文案是否恰当。
3. **导出 HTML / PDF / Word** 后图片是否内嵌可用、网络图自检弹窗是否触发。
4. **图片在表格单元格内**：探针确认可渲染，但**点击不进入选中态**（`isImageBlockRaw` 判定为块级，格内图片无蓝框 / 无缩放 / 无右键菜单）——即格内图片**无法调尺寸与图注**，需确认是否为预期（建议：若预期，则在规范中写明；若非预期，登记 P3）。
