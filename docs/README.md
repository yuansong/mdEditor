# mdEditor 文档中心

本目录收录 mdEditor 项目的开发、设计、竞品研究与历史归档文档。按用途分为以下子目录，便于不同角色快速定位：

## 📁 目录导航

### `dev/` — 开发文档
面向开发者与维护者的工程文档：内部规格、优化路线、缺陷清单、验收规格与跨平台打包说明。
- `OPTIMIZATION.md` — 性能与体验优化记录
- `功能列表-v3.31.md` — 功能全量清单
- `未实现BUG与优化清单-v3.30.11.md` — 已知未实现项与优化建议
- `未实现功能决策清单-v3.38.md` — 功能取舍决策记录
- `格式化操作全量组合测试报告-v3.38.md` — 格式化回归测试
- `编辑器内核路线-宿主模型与无感化-v3.48.17.md` — 编辑器内核演进路线
- `跨平台打包与分发-v3.47.md` — 打包与分发指南
- `单区体验验收规格-OneSurfaceSpec.md` — 单区（One Surface）体验验收规格
- `BOOKLINK-设计说明书-v3.45.md` — BookLink 功能设计说明

### `design/` — 设计方案
产品与交互设计提案。
- `AI助手改造设计方案-SoloMD对标.md` — AI 助手改造方案（对标 SoloMD）
- `UI重设计方案-v3.39.14.md` — UI 重设计总体方案
- `主界面功能与菜单全量清单-v3.39.14.md` — 主界面功能与菜单清单
- `主界面效果图与现有版本对比分析-v3.39.14.md` — 效果图对比分析

### `competitive/` — 竞品研究
- `COMPETITIVE.md` — 竞品分析总览（SoloMD 等，随版本持续更新）
- `scorecard-v3.48.24.md` — Markdown 编辑器评分榜（v3.48.24 全量复评，mdEditor 首次登顶 85.5）

### `ui-redesign/` — UI 重设计原型
- 各视觉风格效果图：`00_界面风格总览.html`、`01~06_主界面效果图-*.html`（Win / Mac / Code / Ribbon / Notion / Zen）
- `02_视图菜单.png` — 视图菜单截图
- `_ref/` — 参考素材与原型（含 `元宝Fluent原型-主页面.html` 与截图）

### `user-guide/` — 用户手册入口
- 完整用户手册随应用分发，源文件见 [`../src/使用手册.md`](../src/使用手册.md)。
- 详细说明见 [`user-guide/README.md`](user-guide/README.md)。

### `archive/` — 历史归档（只读）
历史版本的报告、交互规范与早期竞品分析。**仅作历史留档，不建议作为当前实现依据**；其中含历史 checkout 路径，未做环境通用化处理。

## 📌 说明
- 文档文件名中的版本号（如 `v3.48.x`、`v3.39.14`）标注了对应的设计/决策版本，便于追溯。
- 竞品分析统一维护在 `competitive/COMPETITIVE.md`；散落的旧版独立调研文件已并入该文件或移入 `archive/`。
- 用户手册与代码内文档保持单一来源（`src/使用手册.md`），避免内容漂移。
