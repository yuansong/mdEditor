## 1. 整体功能概述

mdEditor 是一款基于 Python + PySide6 (QtWebEngine) 的**本地单机 Markdown 编辑器**，内核为单文件 `editor.html`，采用**块级所见即所得（WYSIWYG）**编辑模型：每个 Markdown 块（段落/标题/表格/代码块等）渲染后可直接编辑，脱离"源码与预览两张皮"的传统模式，交互对标 Typora。

核心能力一览：

- **文档管理**：多标签页、自动保存、版本历史快照与 diff 对比、最近文件、多编码读写
- **块级编辑**：三视图模式（写作 / 源码 / 分屏）、斜杠菜单、块菜单、丰富的格式快捷键
- **增强语法**：表格（合并单元格、表头、标注、右键操作）、数学公式（KaTeX）、图表（Mermaid）、脚注、定义列表、待办列表、代码高亮
- **图片管理**：本地落盘 / Base64 内嵌双模式、粘贴截图自动保存、右键重命名 / 转换 / 复制
- **导航检索**：大纲（拖拽调序、分节字数、级别过滤）、目录树、查找替换（正则、全量高亮）、全局搜索、命令面板（拼音匹配）
- **导出**：HTML（离线单文件）、PDF（书签）、Word (docx)、EPUB 3，可选 pandoc 增强通道
- **个性化**：六套主题、缩放、打字机 / 专注模式、斜杠菜单配置、快捷键自定义、图表主题

## 6. 通用使用限制汇总

1. **单机本地应用**：无云同步、无协作、无移动端；数据即本地文件。
2. **无单实例机制**：重复启动会开多个进程（尚未实现单实例互斥）。
3. **导出依赖**：Word 依赖 python-docx、PDF 书签依赖 pypdf（打包版已内置）；pandoc 为可选增强。
4. **全局搜索上限**：1500 文件 / 单文件 1.5MB / 400 命中（防止卡顿，超大目录建议缩小范围）。
5. **增强语法的存储升级**：复杂表格（列宽/合并/标注）以 HTML 存储，其余尽量保持原生 Markdown；因此含复杂表格的 `.md` 在其它编辑器中可能显示为 HTML 片段。
6. **懒渲染阈值**：文档 ≥ 400 块才启用，普通文档全量渲染，无感知差异。
7. **版本快照条件**：自动保存写盘与手动 Ctrl+S 均生成（60 秒节流、内容相同去重）；快照目录名为文档名不含扩展名。
