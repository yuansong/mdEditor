VS Code 工作风要点（对标 VS Code / Zed）
  1. 浅色基底（VS Code Light+）：#FFFFFF 编辑区 + #F3F3F3 侧栏/标签栏 + #E8E8E8 标题栏/活动栏 + #007ACC 蓝状态栏，开发者用户零适应。
  2. 深浅双态：界面默认是浅色；用户切到深色主题（深色/墨夜/熊猫）时自动转 VS Dark（#1E1E1E 编辑区 + #252526 面板）。两套取值分别对应 code.json 的 palette 与 palette_dark，可用右上角「◐ 深色示意」按钮对照。
  3. 活动栏：替代左竖工具栏——资源/搜索/历史版本(时间线)/大纲 + 底部设置，图标 + 左侧蓝色指示条选中态（深色态下指示条转白）。
  4. 面包屑：编辑区上方路径导航（VS Code 惯例）。
  5. 状态栏：增加 UTF-8 / Markdown 语言标识，信息密度高于 R7。
  6. M 标记：未保存文件在侧栏显示 M（modified），替代 ● 符号。
  7. 缩略图（minimap）：编辑区右缘文档结构鸟瞰（标题加粗块/正文细线/表格块），视口半透明框可拖动——长文档导航的 VS Code 标配。
  8. 功能与 R7 一致：5 菜单、右端视图状态区、「/」插入 + 命令面板强化（Ctrl+Shift+P）。
