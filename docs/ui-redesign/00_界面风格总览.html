用法
  1. 界面风格：外观(A) → 界面风格 → 选 01~06，下方舞台原地换成该风格的完整界面（结构 + 配色 + 组件形态全部替换，不是仅换色）。
  2. 代码风格：外观(A) → 代码风格 → 经典 / 深色 / 护眼 / 极简（4 项，仅同步选中态）。
  3. 主题：外观(A) → 主题 → 选其一，当前界面的令牌（编辑区底色 / 侧栏 / 菜单栏 / 强调色 / 文字层级）随主题改写；之后再切换「界面风格」时主题保持不变。
  4. 外观(A) 菜单现仅保留三项子菜单：主题 / 界面风格 / 代码风格（原「图表风格」与「外观设置…」已删除）。
  5. 每份风格文档末尾均附加同一组静态场景：入口链路 · 系统设置（新导航 编辑器/通用/模板）· 界面风格选择器 · 代码风格 · 代码块全态 · 右键菜单 · 悬浮工具栏/格式化菜单 · 大纲。
  6. 风格文档：docs/ui-redesign/0N_主界面效果图-PS01-XXX.html，6 套取值均以其 :root 令牌为准，未臆造。
