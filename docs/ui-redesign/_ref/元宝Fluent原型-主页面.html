欢迎使用 Markdown

这是 mdEditor 的主页面原型。界面语言取自 macOS，功能覆盖清单 v3.39.14 的全部入口。

好的工具应当消失在内容背后。

一、从这里开始

  1. 按 <kbd>⌘/Ctrl</kbd> + <kbd>/</kbd> 唤起块菜单
  2. 在空行输入 / 唤起斜杠菜单
  3. 选中文字，出现悬浮格式栏
  4. 点击代码块顶栏可切换语言 / 风格 / 行号

快捷键速记

操作快捷键说明
加粗Ctrl+B选中后生效
块菜单Ctrl+/空块等价斜杠菜单
命令面板Ctrl+Shift+P全功能搜索
历史版本Ctrl+Shift+H快照 + 行级 diff

def class="tk-f">render(md: str) -> str:

    return class="tk-s">''.class="tk-f">join(blocks)
